# MySQL 实时查询安全

- 使用独立只读账号；Fixture 中 `structured_reader` 在数据库层被验证不能执行 UPDATE 或 CREATE TABLE。
- 标识符只来自已发现 Schema 和活动映射，由 MySQL 方言编译器引用。
- 字面量全部参数绑定；拒绝 raw SQL、多语句、DDL、DML、系统库和未授权对象。
- 事务设置为只读，配置连接/执行超时、最大行数、最大返回字节和并发边界。
- 预览不支持 JOIN/函数/子查询；语义查询只支持 Query IR 白名单函数、运算符、聚合和窗口。
- 数据库错误标准化为公开错误，不返回连接串、账号或底层敏感信息。

生产部署必须为每个业务源库创建最小权限账号，不得使用 root；Fixture root 密码只存在于 tmpfs 集成测试容器环境。
