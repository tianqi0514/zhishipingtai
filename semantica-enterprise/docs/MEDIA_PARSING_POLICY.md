# 媒体解析策略

## 使用顺序

管理员在“配置中心 → 解析与加工 → 媒体解析策略”创建并测试策略；可设系统默认、绑定知识空间或绑定数据源。上传时还可以显式选策略并进行一次性覆盖。优先级是：本次上传显式配置 > 数据源绑定 > 知识空间绑定 > 系统默认。任务创建后保存不可变快照，后续编辑策略不会篡改历史运行。

## 抽帧模式

| 模式 | 关键输入 | 适用业务 | 行为 |
|---|---|---|---|
| 固定间隔 | `interval_seconds` | 会议录像、培训视频 | 每隔 N 秒抽帧，保留首尾帧配置 |
| 固定 FPS | `frames_per_second`/`fps` | 短视频、动作变化较快 | 按每秒帧数计算，最高 2 FPS |
| 场景 | 阈值、最短/最长场景、场景内位置 | PPT、产品演示 | ffmpeg 场景检测后按开始/中间/结束抽帧 |
| 智能 | 场景参数、最大兜底间隔 | 内容类型未知 | 场景优先，并用最大间隔避免长静态段无证据 |

所有模式受 `start_seconds`、`end_seconds`、`max_frames`、图像最长边、JPEG 质量和 pHash 去重约束。上传探测会给出预计帧数；超过前端安全阈值时必须二次确认。

## ASR、OCR 与 Vision

- ASR：模型配置、语言、自动检测、分段时长、重叠、最短有效语音、静音策略、说话人/音频事件能力声明。
- OCR：启停、中文/英文语言包、最低词置信度。
- Vision：模型配置、云/本地执行、批次、并发、超时、最大输出和提示词版本。并发由有界线程池真实执行，单帧响应仍独立校验和审计。
- `failure_mode=partial` 保留成功阶段并产生可检索的降级结果；`fail` 使任一必需阶段失败整个解析。`silence_policy=fail` 不受 partial 覆盖。

## 云端确认

- `per_upload`：每次上传或同步显式确认。
- `always_allow`：策略已由管理员批准持续云处理。
- `disabled`：禁止云端 Vision。

页面和 API 同时校验；本地策略若指向没有 `local_runtime` 标识的云模型会拒绝调用，绝不静默切换执行边界。

## CRUD 与版本

支持创建、查看、编辑、复制、删除、启停、设为默认、校验、查看版本和使用记录。已被文档使用的版本不会物理删除。每次编辑生成新版本，运行记录保留策略 Hash、模型引用、提示词版本和执行时间。
