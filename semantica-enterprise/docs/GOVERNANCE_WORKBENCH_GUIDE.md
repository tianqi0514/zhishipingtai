# 治理工作台业务与操作说明

## 业务定位

治理工作台用于集中发现知识质量问题、完成业务修正并跟踪生效结果。它不是审批中心，也不会替代 Semantica 的自动治理：系统先保存解析、画像、切片、实体、关系和冲突等自动结果，人工操作再以追加式决定叠加到有效投影上。任何调整都保留操作者、时间、原因、作用范围、前后值、发布状态和回滚链路。

## 使用顺序

| 顺序 | 页面 | 用户目标 | 关键操作 | 系统结果 |
|---:|---|---|---|---|
| 1 | 待处理 | 优先处理系统发现的问题 | 按状态、优先级、问题类型、文档和关键词筛选；点击问题卡片 | 右侧展示系统结果、当前生效值、来源、影响范围和建议 |
| 2 | 待处理详情 | 决定是否需要人工干预 | 接受自动结果、修正画像、忽略问题、查看原文/图谱 | 关闭或更新待办；处理原因进入审计记录 |
| 3 | 查找知识并治理 | 没有待办时主动治理 | 搜索文档画像、原始内容、检索片段、实体或关系 | 跳转到对应业务页面并定位治理对象 |
| 4 | 文档/图谱详情 | 调整实际业务值 | 修改画像、内容、片段、实体或关系 | 自动结果保持不变，当前有效值即时合成或进入发布任务 |
| 5 | 人工调整 | 按业务操作查看历史 | 展开批次查看字段前后值、原因、范围和影响 | 同一次多字段修改合并为一条业务记录 |
| 6 | 发布记录 | 跟踪下游是否生效 | 查看百分比、知识/图谱/索引版本；失败重试 | 发布成功后切换新版本；失败时旧版本继续服务 |
| 7 | 批次回滚 | 撤销一次业务操作 | 预览对象和影响模块后确认回滚 | 恢复上一人工值或 Semantica 自动值，并按需生成新发布 |

## 页面规则

- 默认进入“待处理”，高优先级问题排在前面，同优先级按发现时间倒序。
- 页面不向普通用户展示 UUID、内部英文代码或原始 JSON。
- 标签、关键词、主要对象使用可逐项添加和删除的标签组件。
- 时间范围使用开始/结束日期控件。Semantica 只识别出年份等非标准日期时，页面显示原值；用户未操作日期控件时不会清空它。
- 多字段画像修正由一个原子接口提交，避免部分字段成功、部分字段失败。
- 调整说明是业务追溯依据。画像、内容和检索片段修正必须填写；忽略待办必须填写忽略原因。
- 内容元素修正会重新进入 Semantica 切片、抽取、归一化、冲突治理和发布链。
- 检索片段修正只重建搜索投影；实体和关系修正重建图谱与组合发布。
- 发布中会显示真实任务百分比。失败任务可以重试，且不会覆盖当前有效发布。

## 工作台 API

| 方法 | 地址 | 用途 |
|---|---|---|
| GET | `/api/v1/curation/workbench` | 工作台指标、筛选后的待办、可选文档和当前发布 |
| GET | `/api/v1/curation/cases/{id}` | 待办业务详情、系统/当前值对照、建议和深链接 |
| PUT | `/api/v1/curation/cases/{id}` | 接受、忽略、重开待办并记录原因 |
| GET | `/api/v1/curation/targets/search` | 在有权限的知识空间内搜索可治理对象 |
| POST | `/api/v1/curation/profiles/{version_id}` | 原子提交画像多字段修正 |
| GET | `/api/v1/curation/batches` | 按业务批次查看人工调整和发布状态 |
| GET | `/api/v1/curation/batches/{id}` | 查看批次字段、影响、任务和发布版本 |
| POST | `/api/v1/curation/batches/{id}/rollback` | 按业务批次回滚当前仍生效的决定 |
| POST | `/api/v1/jobs/{id}/retry` | 重试失败的重新加工或治理发布任务 |

所有接口由 FastAPI 校验登录用户、租户和知识空间读写权限。浏览器不直接访问 PostgreSQL、Worker、OpenSearch、Qdrant 或 FalkorDB。

## 验证清单

1. 在 1280×720 和 1440×900 下打开治理工作台，工具栏、指标、筛选和双栏内容完整可见，无页面级横向滚动。
2. 无待办时显示最近自动治理时间，并能点击“查找知识并治理”。
3. 有待办时点击左侧卡片，右侧展示系统值、当前值和来源；接受后可从“全部状态”重新打开。
4. 忽略弹窗直接取消不触发校验；确认忽略时必须填写原因。
5. 修正画像时添加、删除标签，修改日期和作用范围；无实际变化时保存按钮保持禁用。
6. 保存多字段画像后，“人工调整”只出现一个批次；展开可查看字段前后值。
7. 发布记录显示真实任务进度；失败任务可重试。
8. 回滚弹窗显示目标和受影响模块；回滚后当前值恢复且历史记录保留。
9. 检查浏览器控制台没有 error/warn，服务日志没有未处理异常。
