## 测试中发现并修复的问题

| 问题 | 根因 | 修复 | 回归 |
|---|---|---|---|
| 专业查询示例按中文关系返回 0 | 关系 URI 为百分号编码，图谱未给关系 URI 写入中文标签 | 在授权图谱投影中增加 `rdfs:label`，结果渲染使用业务名称；示例改为按标签查询 | 专项单元和 live SPARQL 均通过 |
| 已失效筛选没有可读对象名 | 运行比较只返回实体 ID | 比较响应增加主体、客体名称和上一运行 ID；前端显示历史结论并可跳转 | 单元测试覆盖 |
| 规则组删除会静默解除任务绑定 | 删除接口直接把任务规则组置空 | 有依赖时阻止删除并返回任务名称 | 单元测试与 live 清理顺序覆盖 |
| 验收数据库 `f4356187` 无法连接 | `structured-postgres` 停运，API 普通 Compose 重建后缺少验收内网白名单 | 恢复双方言验收容器并用覆盖 Compose 重建 API/Worker | 连接、7 表 42 字段发现、实时预览均成功 |

## 已知边界

- 当前规则编辑器只承诺 AND 多条件、主体/客体绑定和二元关系结论；未伪装支持 OR、NOT 或数值表达式。
- 实时金额、同比、排名等问题仍由结构化语义查询处理，不由 Datalog 关系推演代替。
- 大模型自然语言生成规则草稿属于可选增强，本轮未作为完成条件；无模型时手工向导完整可用。
