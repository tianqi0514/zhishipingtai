# 妙笔推演工具箱

## 业务定位

推演工具箱是报告生成前的后台执行层，不是普通用户需要配置的算法后台。页面展示“已完成资源缺口测算”“已完成灾害等级判断”等业务结果；公式、规则和运行标识只在“查看依据”中出现。

## 四类执行能力

| 类型 | 负责内容 | 权威来源 |
|---|---|---|
| 公式计算 | 人员、床位、帐篷等需求和缺口 | 版本化公式与已确认输入 |
| 规则推演 | 灾害等级、响应建议、责任与影响关系 | Semantica Datalog 与 Provenance |
| 数据查询 | 实时库存、床位、车辆等 | 严格 Plan/IR、参数化只读 SQL |
| 算法工具 | 路线、调度和方案比较 | 受控算法及其输入、版本和结果 |

当前地震验收真实计算：搜救人员缺口 180 人、县域床位缺口 220 张、全域床位缺口 80 张、帐篷缺口 1,800 顶。灾害等级由 Semantica 使用确定性判据事实推导；没有让大模型直接比较数值或产生正式结论。

三套方案使用不同优化目标真实执行，分别偏向响应速度、安全风险和综合平衡，不是同一结果的文案改写。

## 安全边界

- 浏览器不执行公式。
- Harness 不直接访问数据库或搜索中间件。
- 模型不能提交原始 SQL，也不能修改计算结果。
- 每个工具支持超时、取消、错误标准化和审计。
- 执行过程保存在 Harness Session Event；正文只接收结构化最终章节。
