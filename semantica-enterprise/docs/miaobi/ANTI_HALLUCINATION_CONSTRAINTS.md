# 妙笔防幻觉约束

系统不能承诺模型理论上的绝对零幻觉，但可以阻止无依据内容进入正式稿。

| 内容类型 | 权威来源 | 正式稿约束 |
|---|---|---|
| 精确事实 | verified Fact + Evidence | 缺任一绑定即阻止定稿 |
| 精确数值 | Fact 或结构化 QueryRun | 名称、值、单位、范围必须匹配 |
| 计算结果 | 不可变 ComputationRun | 记录输入、公式版本和输出 |
| 规则结论 | Semantica 推演及证明链 | 模型不得冒充正式推演 |
| 公开标准 | 已登记 URL、机构、日期和引用片段 | 其他地区职责和数值不得套用 |
| 叙述衔接 | DSH Agent | 标记 narrative，不伪装成事实 |

每个 Chunk 生成后检查数字、单位、名称、时间、适用范围、来源版本、冲突和引用支持度。发现 unsupported 内容时只允许删除、改写为不确定表述或补充依据，不能补造引用。
