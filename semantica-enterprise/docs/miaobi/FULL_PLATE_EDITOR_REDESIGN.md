# 妙笔完整 Plate 编辑器与知识闭环重构

## 审计结论

`miaobi-v1.0.0-rc1` 使用了 Plate 53 的编辑内核、协同、评论和修订插件，但界面只暴露了少量按钮。它属于业务闭环候选版，不满足“完整 Plate 编辑器”的产品验收：没有可用的 `/` 指令菜单、完整块类型、浮动格式栏、专业表格操作、文档导入和清晰的知识来源联动。

本轮以锁定的 Plate commit `8f65d77f8b4709833436e63661e4d061f709258f` 中 `plate-playground-template` 为功能基线，只使用 Plate 官方开源插件 API，自行实现传神智库风格的 UI，不复制 Plate Plus 商业组件。

## 目标体验

正文保持专业文稿的连续阅读体验。知识引用、确定性测算和规则推演只在正文旁显示轻量编号或状态标记；来源详情、计算输入、公式、规则、前提、版本和时效统一在右侧展开。

编辑器提供两类入口：

- 固定工具栏：高频排版、插入、审阅、导入和保存。
- `/` 指令：在光标位置搜索并插入标题、列表、待办、引用、提示块、表格、分栏、日期、公式、图片、知识依据、测算值和推演结论；“妙笔助手”指令打开右栏并聚焦输入框。

## Plate 能力基线

| 能力 | 本轮实现方式 |
|---|---|
| 基础块与六级标题 | Plate Basic Nodes 与 Markdown 输入规则 |
| 粗体、斜体、下划线、删除线、高亮、上下标、行内代码 | Plate Marks |
| 字体、字号、颜色、背景色 | Plate Basic Styles |
| 对齐、缩进、行距 | Plate Basic Styles 与 Indent |
| 有序、无序、待办列表 | Plate List |
| 引用、提示块、折叠块、分栏 | Plate 官方元素插件 |
| 表格与行列、合并拆分 | Plate Table transforms |
| 链接、图片、日期、公式、脚注、目录、代码块 | Plate 官方插件与本项目 UI |
| `/` 指令菜单 | Plate Slash Command + Combobox |
| 评论与修订 | Plate Comment + Suggestion |
| 多人协同 | Plate Yjs + 自建 Hocuspocus |
| Markdown/HTML | Plate 序列化与受控导入导出 |
| Word | Plate DOCX 粘贴/导入；正式发布继续走服务端模板导出 |
| AI 写作 | DeepSeek Harness Agent Loop，通过右栏驱动 Plate 修订，不绕过知识权限 |

## 与传神智库的可见交互

```text
传神智库上传/接入
  → 解析、治理、语义建模、发布知识版本
  → 知识产品 Release（妙笔锁定）
  → 妙笔按 Release 检索/读取片段/图谱/结构化数据
  → 生成待确认草稿
  → 正文轻量依据标记
  → 右栏核验证据、计算和推演
  → 审校、版本与正式导出
```

妙笔任务概览必须展示当前知识产品版本、所含知识空间、文档/片段/图谱状态及更新时间，并提供“去智库接入材料”“查看知识资产”“更新知识基线”入口。更新基线是显式操作；切换 Release 后，旧绑定标记为过期，不静默改写正文。

## 真实质量验收

新增从上传开始的端到端脚本，验证：

1. 上传客户材料的脱敏副本。
2. 轮询解析、切片、治理和索引发布。
3. 发布知识空间和知识产品 Release。
4. 新建妙笔任务并锁定 Release。
5. 以业务问题触发 DSH 检索、推演和确定性计算。
6. 生成目录与章节草稿。
7. 校验每个关键结论的正文绑定与右栏依据。
8. 按完整性、事实正确性、引用覆盖率、引用有效性、结构、可读性、术语一致性和未知事实八项评分。
9. 低于门槛时输出可执行缺口，回溯修复解析、检索、规则、提示词或模板，而不是修改期望结果。
10. 导出 DOCX/PDF 并实际打开检查。

## 验收边界

- “插件已安装”不等于功能完成，必须能在浏览器真实操作。
- 大模型草稿不是正式事实；没有来源的事实性陈述必须被审校标记。
- Plate AI 能力由 DSH 统一编排，避免形成第二套无权限边界的模型调用。
- 正式 DOCX/PDF 以服务端模板为准；Plate 负责编辑和交换，不承担最终公文版式权威。
