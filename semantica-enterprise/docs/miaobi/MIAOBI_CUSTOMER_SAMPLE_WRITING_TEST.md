## 从 63 分到 100 分的修复

1. 增加 `WritingGenerationRun`，将九章生成收敛为一个有状态的一键任务。
2. 章节只接受严格 JSON 协议，不再拼接完整 Assistant 回复。
3. 拦截英文工作草稿、工具过程、重复标题和重复长句。
4. 由服务端插入 `computed_metric`、`inference_conclusion` 和引用节点。
5. 未通过硬门禁时不覆盖当前正文，也不能显示审校通过。
6. DOCX/PDF 统一 A4，正文引用可见，并单独生成推演依据说明。
7. 建立输入变化预览和局部更新，避免整篇静默重写。
