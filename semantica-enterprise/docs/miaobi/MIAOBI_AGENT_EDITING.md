# 妙笔 Agent 编辑

## 编辑方式

用户可选中文字后右键执行扩写、改写、缩写、更正式或更简洁，也可在右侧对话中指定章节和目标。Agent 编辑使用单独的写作 Session，不与一键生成的九章 Session 混用。

操作分三步：创建编辑请求、Harness 生成建议、用户接受或拒绝。建议保存原文、建议文本、范围、状态、模型和审计信息；拒绝不会改变正文，接受后产生新的文稿版本。

## 约束

- 只修改用户选中或明确指定的范围。
- 不改变可信数值、推演结论和有效引用。
- 不将工具执行过程或私有思维链写入正文。
- 没有真实来源时只能标记“尚未绑定依据”，不能伪造引用。
- 若用户要求改变事实，提示返回输入确认并走影响预览。

服务端会校验建议是否篡改受保护值、删除有效引用或引入平台内部说明；校验失败的建议不能被接受。
