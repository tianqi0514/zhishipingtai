# 妙笔安全设计

## 权限

- 所有写作对象带 `tenant_id`，读取和修改时校验项目成员、角色、知识产品 Release 和来源空间权限。
- DSH、协同和下载均使用有作用域的短期凭据；长期模型密钥和数据库密码不进入前端或 Session Event。
- 文稿绑定打开来源时重新校验权限，不能凭已保存的 Chunk ID 越权。

## 不可信输入

文档、HTML、Markdown、模型输出和 MCP 返回都视为不可信数据。前端渲染进行转义；工具返回不能改变系统指令；结构化查询拒绝原始 SQL；公式不执行用户表达式；文件名经过路径和响应头安全处理。

## 发布与审计

待确认闸门、失效块、缺失来源或高风险冲突会阻止正式发布。人工覆盖必须记录原值、新值、理由、操作者和影响范围。发布版本不可变，删除使用软删除。下载、确认、评论、推演、计算和导出均有审计记录。

## Secret

Secret 只来自 Docker Secret、受保护环境文件或平台加密模型配置。测试和文档仅使用占位符。提交前应运行只输出文件名的 Secret 扫描，避免在控制台打印匹配内容；曾在聊天中暴露过的真实 Key 应由管理员轮换。
