# 妙笔写作工作台浏览器测试

## 浏览器验收路径

1. 登录后打开 `/miaobi/`。
2. 新建空白项目，确认创建后直接进入项目详情。
3. 在无文章状态下只出现“新建文章”，不启动 Agent、不显示技术配置错误。
4. 新建两篇不同文章，验证文章类型、用途、读者、适用范围和材料选择互相独立。
5. 在妙笔内上传材料或选择知识空间；验证解析状态和真实失败原因。
6. 在“准备资料”确认材料用途、关键事实和目录。
7. 在“起草编辑”仅生成具备条件的章节。
8. 打开 Plate，输入 `/`，验证真实命令菜单；编辑标题、段落、列表和表格。
9. 使用右侧助手生成修改建议，分别接受和拒绝，不静默覆盖正文。
10. 点击正文引用，在右侧打开同一版本来源。
11. 修改共同输入，预览计算、推演及正文影响；应用前正文不变，应用后仅更新已绑定位置。
12. 检查后导出 DOCX/PDF，并实际打开检查中文、分页、表格和正文。

## 观察重点

- 普通页面不出现 Release、Datalog 变量、Query IR、内部 UUID。
- 生成按钮不能覆盖已经人工编辑的文稿。
- 无知识空间仍可创建项目和空白文章；使用检索或生成时才提示添加资料来源。
- 页面在 1280×720 和 1440×900 下无整页横向滚动。
- Console 无错误，取消不提交，重复点击不产生重复任务。
