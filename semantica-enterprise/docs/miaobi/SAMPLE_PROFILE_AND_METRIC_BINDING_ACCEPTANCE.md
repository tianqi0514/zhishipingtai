# 妙笔：样稿配置与指标联动验收（2026-09-15）

本轮按两条独立标准验收。验收数据是测试/讨论稿，不代表正式行政预案或真实灾情。

## 1. 样稿配置、新项目与文章质量

输入为客户提供的《样稿.pdf》（19 页）及另行上传的《临夏州地震应急预案.docx》。PDF 只承担结构和文体样本角色；正文事实、部门职责和响应条件只能来自后者的当前有效版本与可核验片段。脚本 `scripts/miaobi/acceptance_sample_profile_writing.py` 在独立验收空间创建项目和文章，幂等识别已上传版本，不覆盖其他空间。

从 PDF 提取并经用户确认的配置包括：七个一级章节（总则、组织体系、运行机制、应急保障、其他地震事件应急、监督管理、附则）、每章写作提示、正式预案文体、多级标题编号、通知/签发需要授权、三个附件标题。样稿没有稳定的计算指标或公式，所以候选数量均为 0；系统没有编造指标。编辑器现在能展开查看已确认的完整配置，而非只显示章节摘要。

使用真实 DeepSeek Harness 分章生成与知识工具检索。第一次正文不足样稿正文长度的 75%，质量门禁没有放宽，而是对不足章节启动新的真实 Agent Turn 定向补写；随后又修订了末尾“实施时间”表述，避免将依据文件的旧签发语句套入项目讨论稿。当前生成运行已完成，文章版本为 3：七章均出现一次，正文约 8,086 个紧凑字符，是样稿**正文**（剔除通知、目录和附件）约 10,293 字的 78.56%；有 67 个正文引用标记，长句重复率约 2.91%。浏览器点击引用后由受保护接口获取真实知识片段，而非引用 PDF 样稿或静态正文。

Word 已从当前 Plate 文稿版本真实导出并逐页渲染检查，共 7 页：A4、中文多级编号、标题层次、页码、中文正文无乱码或裁切。**尚未达到可签发的生产质量**：客户样稿的通知、三份实质附件及逐条人工业务审定没有在这次讨论稿中生成；通知本身须有授权签发信息，附件也须对应可靠业务材料，不能从样稿复制或以空白占位冒充。正文结构与正式文体已有接近性，但不能把 78.56% 长度比或引用数量等同于客户业务验收。

## 2. Plate 中的指标绑定和选择性应用

使用独立模拟项目/文章（不复用客户样稿项目）。测试原子输入为“搜救人员需求 500、可用搜救人员 320”，确定性公式 `max(需求量－可用量, 0)` 得到缺口 180。Plate 正文同时含段落、表格、测算呈现和摘要四处已登记依赖，另有无绑定文本。

在编辑器输入新值 400 后，后端计算候选缺口 100，并在应用**之前**返回直接和间接影响。弹窗列出每个位置与旧/新内容，允许“全部接受”或逐项勾选；取消不会改变正文。真实浏览器测试先只选 3/4 项：选中的段落、表格和测算呈现变为 100，未选摘要保留 180 且标记待处理；无绑定文字不变。随后可选择全量应用，系统创建不可变的新文稿版本。保存以 Plate/Yjs 当前正文为权威，影响预览使用版本和内容指纹检查，避免过期预览误应用。它不是字符串全局替换：未登记依赖的相似句子只能提示疑似影响，不能保证自动更新。
