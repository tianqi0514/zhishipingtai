# 地震场景验收基准

以下值来自客户提供的推演数据表、推演依据说明和方案样稿。验收程序需要从 Fixture 输入重新计算，不能把结果作为回答模板。

| 指标 | 输入或预期 | 单位 | 处理方式 |
|---|---:|---|---|
| 震级 | 6.2 | 级 | 官方简报事实 |
| 人口密度 | 305.6 | 人每平方公里 | 客户推演数据 |
| 灾害等级 | 重大地震灾害（II 级） | - | 数值判据事实 + Semantica 推演 |
| 搜救人员需求 | 500 | 人 | 公式运行 |
| 搜救人员可用 | 320 | 人 | 实时或确认事实 |
| 搜救人员缺口 | 180 | 人 | `max(0, required - available)` |
| 创伤床位需求 | 330 | 张 | 公式运行 |
| 县域可用床位 | 110 | 张 | 实时或确认事实 |
| 可调用床位 | 250 | 张 | 聚合后的确认事实 |
| 县域床位缺口 | 220 | 张 | 公式运行 |
| 全域床位缺口 | 80 | 张 | 公式运行 |
| 帐篷需求 | 7000 | 顶 | 公式运行 |
| 帐篷可用 | 5200 | 顶 | 实时或确认事实 |
| 帐篷缺口 | 1800 | 顶 | 公式运行 |

变更用例：将搜救人员可用量从 320 改为 400，预期缺口从 180 变为 100。只依赖该事实的 ComputationRun、推演结论和正文块进入 `stale`，其他章节保持当前状态。

客户表中救护车和部分资源存在口径冲突。该类值不纳入无确认的正式 Ground Truth，必须生成 FactConflict 并由业务用户选择口径。
