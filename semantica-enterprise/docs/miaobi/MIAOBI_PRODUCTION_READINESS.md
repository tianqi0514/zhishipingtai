## 生产边界

- 地震以客户材料完成深度技术验收；其余六类仅通过确定性协议与链路验收，正式规则必须由客户业务部门确认。
- 路线能力当前使用受控 Dijkstra/风险权重算法；尚未接真实商业 GIS 和实时交通。
- 协同服务当前采用单实例文件持久化；多副本生产扩展需要共享持久化层。
- Reranker 未配置时明确降级到 RRF，不伪装成模型重排。
- 真实模型 429 和中间件故障由单元/协议级测试覆盖；不会通过停止共享持久化服务破坏当前演示数据来制造故障。
- 内网服务器为 32 vCPU、251 GiB 内存、约 792 GiB 可用磁盘，但没有 NVIDIA GPU；不适合在本机直接运行 Qwen3.8-27B-NVFP4，当前使用独立推理服务。
- 内网当前使用 HTTP。Plate/Yjs 的确定性初始化摘要已兼容非 Secure Context，但正式生产仍应配置 TLS；随机数、JWT、服务端可信哈希和权限校验没有被降级。
