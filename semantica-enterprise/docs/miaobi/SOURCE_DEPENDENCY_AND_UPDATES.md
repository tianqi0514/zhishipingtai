# 来源依赖与联动更新

目标是“自动发现全部已登记影响，预览后应用”，不是静默全文替换。

依赖链：来源片段 → 结构化事实 → 计算/推演 → 正文段落、表格、摘要和其他文章。正文段落可以引用多个来源，一个结果也可以影响多个正文块。

变更流程：保存候选来源或事实版本；按稳定 ID 和版本查找直接与间接依赖；重跑必要计算和推演；为自然语言段落生成修改建议；展示变化前后、受影响章节和其他文章；用户选择应用全部或逐项处理；创建新文稿版本并保留撤销依据。

已定稿文章不自动变化，人工覆盖不被静默替换。没有绑定、仅语义相似的内容只能列为疑似影响。影响预览完成后，如果正文、来源或计算再次变化，旧预览必须拒绝应用。

当前基线已支持事实/计算依赖的失效标记和测算块局部重算，但来源 Chunk 治理变化、普通引用和自然语言段落建议尚需统一为同一套事件与依赖传播机制。
