# 妙笔浏览器测试报告

测试日期：2026-09-10

测试入口：`http://localhost:8080/miaobi/`

测试方式：通过真实浏览器点击、输入、滚动、刷新和网络请求验证，不以 API 测试替代页面测试。

## 简化主流程

1. 登录并打开妙笔。
2. 选择客户样本盲测任务。
3. 默认看到“输入确认—分析计算—报告编辑”三个阶段。
4. 输入区显示业务名称、数值、来源、版本和确认状态，不暴露内部 ID。
5. 分析计算区按业务结果展示 4 个确定性计算、Semantica 推演和三套方案。
6. 一键生成完成后进入完整 Plate 编辑器。
7. 正文显示九个唯一章节、轻量引用、测算和推演标记；右侧展示内容依据。

## Plate 与 Agent

- 工具栏、标题、列表、表格、引用、评论、修订和自动保存可用。
- 输入 `/` 会打开 Plate Slash Command 菜单，不是模拟输入框。
- 选中文字可以右键扩写、改写和缩写；结果先形成建议，可接受或拒绝。
- 右侧妙笔助手使用单独写作 Session，执行过程和正文分离。
- 页面刷新后恢复当前文稿、版本、依据和协同状态。
- 当前盲测正文含 70 个 Plate 顶层节点、4 个可信计算节点、1 个可信推演节点和 111 处可见引用。

## 内容依据

点击正文引用或可信标记后，右侧显示文档、数据、计算或推演依据。来源位置展示为“正文第 N 段”或“工作表名称”，技术路径默认不显示。无依据内容明确标记为未绑定，不伪造引用。

## 影响更新

真实点击修正“可用搜救人员”：

1. 输入 400 并填写理由。
2. 页面先显示影响预览，而不是修改正文。
3. 预览显示搜救人员缺口 180→100、受影响正文内容 1 个。
4. 点击应用后产生新版本，进入编辑器可见 100。
5. 按同一流程恢复 400→320，缺口恢复为 180，无关章节保持不变。

浏览器和服务端的协同快照发生冲突时，一键生成或影响更新产生的不可变服务端版本优先；普通手工保存继续使用 Yjs 恢复，避免服务器正确版本被旧协同快照覆盖。

## 响应式与状态

- 1280×720 下页面无整体横向溢出，正文与右栏独立滚动。
- 保存、生成和应用期间按钮禁用，防止重复提交。
- 弹窗取消不会触发提交。
- 审校区显示“审校通过”仅来自服务端质量门禁。
- 页面可见操作未出现未处理错误；应用服务日志未发现对应未处理异常。

1440×900 和 1920×1080 的基础响应式能力已由现有回归覆盖；本轮简化页面重点重新实测 1280×720。内网新镜像部署后应重新执行同一组页面点击和 Console 复核，不能沿用旧镜像结果。
