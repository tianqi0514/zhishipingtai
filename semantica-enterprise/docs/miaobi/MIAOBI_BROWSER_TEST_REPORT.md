# 妙笔浏览器测试报告

测试日期：2026-09-09

浏览器入口：`http://localhost:8080/miaobi/`
测试方式：真实浏览器 DOM 点击、输入、滚动、网络请求、下载和 Console 检查。

## 已验证主流程

1. 从传神智库应用中心进入“妙笔·应急方案生成”。
2. 打开地震验收任务，核对知识产品版本、事实、计算、推演和三套方案。
3. 进入完整 Plate 编辑器，编辑标题和正文，执行保存、撤销/重做、表格、引用、评论与建议操作。
4. 点击知识引用打开真实 Release 范围内的文档片段。
5. 点击“搜救人员缺口”查看计算输入、公式和不可变运行记录。
6. 点击灾害等级结论查看 Semantica 规则、前提和证据链。
7. 使用妙笔助手发起真实 DSH Turn；流式答案、停止/恢复状态和 Agent 工作过程正常。
8. 刷新后历史对话恢复：2 条消息、138 个投影事件、完成状态和 19 秒真实耗时可见。
9. 五种导出均通过页面按钮发起，返回成功状态并能下载：DOCX、PDF、JSON、XLSX、GeoJSON。
10. DOCX/PDF 下载后实际渲染并检查两页版式；无重复大标题、蓝色装饰线、裁切或乱码。

## 可信内容与错误路径

- 计算块和推演结论块不可直接编辑；用户篡改可信块内容后审校返回 `trusted_block_modified`，不能发布。
- 引用只允许绑定当前项目不可变知识产品 Release 的真实 QueryRun 和 Chunk。
- GeoJSON 缺少路线坐标时页面显示真实失败；补充项目坐标后再次导出成功。
- Reranker 未配置时显示降级，不显示“重排成功”。
- 切换任务和会话不会残留旧计时器或旧流。
- 弹窗取消不提交；保存中按钮禁用，防止重复创建。

## 响应式与滚动

| 分辨率 | 结果 |
|---|---|
| 1280×720 | 三栏可用，编辑器和右栏独立滚动，工具栏与输入区可见 |
| 1440×900 | 通过，无整体横向溢出 |
| 1920×1080 | 通过，目录、正文、证据栏比例正常 |

前端对完整 Plate 编辑器执行延迟加载；应用框架先展示，编辑器加载期间显示明确状态。长对话只在用户位于底部附近时自动跟随，用户查看历史时不被强制拉回。

## Console 和网络

- 最终本机回归 Console：0 个 error，0 个未处理 Promise。
- 已执行主流程无非预期 4xx/5xx。
- 有意触发的 GeoJSON 缺坐标错误为受控业务错误，修复配置后同一操作成功。
- 页面未出现 API Key、数据库密码、内部 Token、系统提示词或模型私有思维链。

## 结论边界

本报告覆盖妙笔地震主演示、可信业务块、DSH 历史恢复、导出和三档视口。六类待确认场景完成 API 技术闭环，但未在浏览器中冒充客户业务验收；客户确认其规则和模板后，需要补做对应的正式浏览器业务验收。
