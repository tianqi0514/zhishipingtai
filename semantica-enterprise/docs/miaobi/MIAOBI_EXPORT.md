# 妙笔正式导出

普通编辑交换可使用 Plate 的序列化能力；正式方案由 FastAPI 服务端按受控模板生成，避免浏览器环境和字体差异影响交付。

## 格式

- DOCX：标题、页眉页脚、页码、多级标题、段落、列表、表格和生成依据摘要。
- PDF：由服务端受控转换链从 DOCX 生成。
- JSON：文稿节点、版本与审计摘要。
- XLSX：已核验事实、确定性计算和备选方案工作表。
- GeoJSON：仅在采用方案有完整可核验路线坐标时生成。

导出固定文稿版本、知识产品 Release、场景包版本、事实/计算/推演数量、采用方案和 Checksum。可信引用在导出时再次清理 HTML 实体及 Markdown 标记，防止将 `#`、`&gt;` 等检索表示泄漏进正式文件。导出结果不包含内部 Token、系统提示词或隐藏审计字段。
