# 影响预览与选择性应用

事实变更采用两阶段协议，不直接改正文。

```text
候选输入变化
  -> 重算直接依赖的 ComputationRun
  -> 按稳定 input_key / metric_key 遍历正文绑定
  -> 生成 ImpactPreview
  -> 用户全选、逐项选择或取消
  -> 原子写入 FactVersion、ComputationRun、ArticleVersion
```

确定影响来自显式依赖；只有语义相似而没有绑定的内容单列为疑似影响，不能自动修改。无可替换数字但依赖已变化的段落以“仅复核”提案保留，接受后更新依赖状态而不伪造文字变化。

真实验收：可用搜救人员 `320 → 400` 后，公式 `500 - 400` 得到缺口 `100`。摘要、处置目标、抢险救援、信息报告、资源缺口和任务表等 11 个已登记影响均可选择；未选项保持原文并标记 stale；重复应用返回 409；历史版本仍保存 320/180。
