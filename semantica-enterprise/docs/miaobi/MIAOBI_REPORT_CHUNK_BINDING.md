# 妙笔报告内容绑定

## 两种内容片段

`KnowledgeChunk` 是传神智库中可检索的来源片段；`ReportChunk` 是报告里可独立生成、引用和更新的内容单元。普通页面统一称后者为“报告内容”。

场景模板确定权威结果的位置，例如灾害等级进入第三章、搜救人员缺口进入第五章、床位缺口进入医疗救治段落、帐篷缺口进入物资保障段落。Agent 可以组织上下文，但不能决定权威结果应该落在哪一章。

## 绑定链

`输入版本 → 计算/推演运行 → 报告内容 → 文稿版本`

每个可信内容保存稳定 `block_id`、来源版本、计算或推演运行、证据、内容哈希和新鲜度状态。服务端在保存、审校和导出前重新验证可信哈希，前端不可编辑属性不是安全边界。

## 正文表现

正文保持普通文章形态。引用表现为 `[n]`，数值和结论使用小型“测算/推演”标记。右侧依据区展示：

- 文档名称、版本、页码或业务化结构位置；
- 数据值、来源和数据时间；
- 计算输入、公式、输出和版本；
- Semantica 前提、规则、结论和证据链。

原始 UUID、内部状态码和工具参数仅可在折叠的技术信息中查看。
