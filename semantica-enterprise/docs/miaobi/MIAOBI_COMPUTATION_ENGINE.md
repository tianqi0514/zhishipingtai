# 妙笔确定性计算与方案算法

权威数值不由大模型生成。妙笔使用白名单公式和受控路线算法，每次运行保存输入、参数、舍入、输出、公式/算法版本和 Checksum。

## 公式

当前引擎实现资源缺口、安置容量缺口、饮水需求、车辆/救护车趟次、医疗分流压力和路线效用评分。公式通过固定 Python 分支执行，不使用 `eval`，也不接受任意表达式。

资源缺口公式为 `max(0, required - available)`。验收基准中搜救人员需求 500、可用 320，结果 180；可用量修正为 400 后结果为 100。依赖图只将相关计算、推演和正文块标记为 `stale`。

## 路线与备选方案

路线使用 Dijkstra 在当前图输入上计算，边包含时间、风险和可用状态。三套方案分别采用速度、安全、综合权重；它们共用同一输入但得出三条不同路线，结果记录分钟数、风险、未满足缺口和计算版本。没有可用路径时返回失败，不回退到写死路线。

## 结构化实时数据

需要实时库存或业务指标时复用严格 Semantic Query Plan、Query IR、MySQL/PostgreSQL 确定性编译器和只读执行器。模型不能提交物理表名、字段名或原始 SQL；FastAPI 负责映射、权限、参数绑定、超时、截断、脱敏和 QueryRun。
