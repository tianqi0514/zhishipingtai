# 综合工作台 HTML 复用审计

参考文件保留了有价值的业务意图：按项目组织、项目基础信息、上传或在线补充、复用历史资料、左侧目录/中间正文/右侧辅助信息，以及从资料到报告输出的连续路径。

可复用：白色工作台布局、项目表单的业务字段、资料角色表达、写作目录、三栏编辑器、紧凑进度和结果摘要的视觉方式。

不能直接复用：localStorage 业务数据库、模拟请求、固定事实、按文件名猜内容、固定计算、静态报告 HTML、预设章节和虚假的上下游影响。原 HTML 不通过 iframe 嵌入，正式实现继续使用 React、FastAPI、PostgreSQL 和 Plate。

原 HTML 的九个一级入口不原样迁移。正式产品只保留项目列表、项目详情/文章列表和写作工作区；资源、事实、分析与审校作为写作步骤中的按需面板出现。
