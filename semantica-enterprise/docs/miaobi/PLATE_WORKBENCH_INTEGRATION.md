# Plate 写作工作台集成

妙笔继续使用 React、TypeScript 和 Plate 53.3.11，Plate 上游代码对应审计仓库提交 `8f65d77f8b4709833436e63661e4d061f709258f`。没有使用 textarea、普通 contenteditable 或静态 HTML 替代编辑器，也没有复制 Plate Plus 商业 UI。

当前编辑能力包括标题、段落、列表、字体、字号、对齐、行距、表格、图片、链接、目录、撤销重做、查找替换、评论、修订、协同以及 Markdown/HTML/DOCX 交换。输入 `/` 由 Plate Slash/Combobox 插件展示渐进命令，复杂能力不堆满工具栏。

妙笔自定义节点只表达轻量绑定：知识引用、已核验事实、计算结果、推演结论、人工假设和风险提示。正文保持正式文章样式；公式、来源、证明和运行信息在右侧查看。

编辑器实时状态由 Yjs/Hocuspocus 协同，正式版本由 PostgreSQL 元数据和不可变正文快照管理。服务端在保存、审校和导出时重新校验可信块哈希，前端只读样式不是安全边界。

生产构建采用懒加载编辑器。完整插件组合仍产生较大的编辑器资源包，这是当前性能限制；不通过删掉专业写作能力伪造体积优化，后续应继续拆分 DOCX、公式和协同相关动态模块。
