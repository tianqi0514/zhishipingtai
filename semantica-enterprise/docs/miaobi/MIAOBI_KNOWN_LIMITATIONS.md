# 妙笔已知限制

1. 地震场景已按客户材料深度验证；洪涝、火灾、地质灾害、冰雪、疫情和反恐维稳虽有独立契约、Fixture 与真实 API 技术闭环，但规则、阈值、公式参数和正式文稿仍需客户业务确认。
2. Plate 完整编辑器采用延迟加载；编辑器功能块约 1.15 MB（gzip 341.93 kB），首次进入“妙笔文稿”仍受内网带宽和浏览器缓存影响。
3. 当前路线算法是受控 Dijkstra 和风险权重模型，尚未接真实商业 GIS、实时交通或跨区域调度系统；GeoJSON 只在路线坐标完整时生成。
4. 当前协同采用单实例 Hocuspocus 文件快照持久化，已验证 5 用户实时同步和重启恢复；多副本扩展仍需要共享持久化和一致性方案。
5. “密级”仅作为文稿元数据和导出标记，不代表已实现涉密信息系统完整安全体系。
6. 其他六类灾种不能在客户确认前用于正式应急指挥，页面和导出数据均保留“模板待业务确认”标识。
7. 云端或内网模型可用性取决于当前模型配置与网络；模型失败会显示真实错误，不回退为假文稿。
8. 路线、天气、医院和库存的外部系统目前使用 Docker 内受控算法/协议服务；接生产系统前需完成目标系统认证、限流和数据口径联调。
9. DOCX/PDF 已完成当前模板的真实渲染检查；不同客户字体、版记和公文套红规范仍需逐模板验收。
10. 客户正式业务验收、灾种专家签字以及高可用多节点部署不包含在当前技术候选结论中。
11. 当前内网服务器没有 NVIDIA GPU，不能在该主机上高效部署 Qwen3.8-27B-NVFP4；生产推理需继续使用独立 GPU 推理服务或为该服务器增加合适 GPU。
12. 当前内网验收入口使用 HTTP。应用已兼容 Plate/Yjs 在非 Secure Context 下的确定性摘要初始化，但正式对外生产必须配置 HTTPS，才能获得完整的传输保护和浏览器安全能力。
