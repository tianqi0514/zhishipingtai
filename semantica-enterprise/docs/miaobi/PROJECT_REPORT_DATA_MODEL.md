# 项目与文章边界

项目承载事项、成员和资料池；文章承载一次具体交付。一个项目可以同时包含应急预案、处置方案和总结报告，它们可以复用资料，但必须独立管理文章类型、模板、采用事实、来源版本、生成进度、审校和定稿。

## 本轮数据模型调整

`WritingDocument` 新增文章级字段：

- `document_type`：文章类型。
- `purpose`：写作目的。
- `audience`：目标读者。
- `applicability`：地区、组织、事项和时间范围。
- `writing_requirements`：文章特有写作要求。
- `scenario_package_version_id`：文章级模板版本；未指定时兼容继承项目默认值。
- `knowledge_product_release_id`：文章级知识快照；未指定时兼容继承项目默认值。

旧项目继续使用原有项目默认值，新文章可以逐步迁移到文章级契约。后续资料采用集也必须下沉到文章，不能只依赖项目资料池。

## 冻结规则

定稿至少冻结：正文版本、文章契约、目录/模板版本、采用材料版本、事实与口径、规则和计算结果、引用绑定、审校结论。共享资料更新只产生影响提醒，不能静默修改任何文章；已定稿文章通过创建修订草稿采用变化。
