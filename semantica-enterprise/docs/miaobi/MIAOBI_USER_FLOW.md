# 妙笔用户流程

## 创建方案任务

1. 在应用中心打开“妙笔·应急方案生成”。
2. 点击“创建方案任务”，输入名称并选择灾种。
3. 选择已发布的知识产品版本。页面同时显示数据时间和版本号。
4. 上传灾情材料或选择已有知识，不强制上传与场景无关的音视频。
5. 创建成功后直接进入“数据与事实”，而不是停留在列表页。

## 核对事实

事实页按“需要处理、已核验、仅供参考、历史失效”分组。用户先处理阻塞项：缺失必填字段、口径冲突、低置信度关键事实。每条事实均可查看来源。人工补齐或覆盖必须填写理由。

## 计算与推演

1. 点击“检查数据”，查看哪些计算和规则可以运行。
2. 点击“开始推演”。页面展示真实阶段和百分比。
3. 数值判据先由确定性服务形成事实，关系结论再由 Semantica 执行。
4. 查看资源缺口、证据链和无法推导的原因。
5. 生成三套方案并比较响应时间、风险、资源缺口和未满足约束。

## 编辑文稿

1. 选择方案后点击“生成文稿”，进入 Plate 编辑器。
2. 左侧选择章节，右侧助手按章节目标检索并生成建议。
3. AI 输出以流式草稿或修订建议进入编辑器。
4. 点击引用、测算值或推演结论可查看真实来源、输入公式或证据链。
5. 用户可以评论、接受或拒绝建议；所有保存有明确状态。

## 审校与发布

1. 系统检查缺失章节、来源、冲突、过期块、术语和格式。
2. 用户处理审校问题并完成必要确认。
3. 生成预览，检查 DOCX 和 PDF 版式。
4. 点击正式发布后生成不可变版本。后续修改需要创建新草稿。

## 数据变化

当库存、灾情或知识 Release 变化时，系统只标记依赖这些输入的业务块。用户查看影响章节，执行局部重算或重推，审核差异后形成新版本；旧版本不被修改。
