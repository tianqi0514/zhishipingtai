# 数据库数据预览

数据库数据源详情包含“数据概览、数据预览、结构发现、语义映射、同步记录、查询测试”。非数据库来源不显示数据库专用页签。

## 实时数据库

- 不需要先同步；后端使用数据源加密 Secret 建立短连接。
- 默认 20 行，可选 20/50/100；单次上限 100 行。
- 表和字段只能来自最新 Schema Catalog；不接受原始 SQL、表达式、JOIN 或子查询。
- 文本、数值、日期、布尔和 NULL 使用类型化筛选并进行参数绑定。
- 有主键时按主键稳定排序；无主键时返回明确 Warning。
- 宽表仅在表格内部横向滚动，页面和右侧行详情不被撑出视口。

## 最近同步快照

快照读取最近 DocumentVersion 的 `record` ContentElement，不访问源数据库。页面显示同步时间和文档版本；没有快照、仍在解析或当前对象没有同步行时返回真实状态，不用假数据替代。

## 字段保护

`password/secret/token/api_key/private_key/credential` 默认禁止预览、筛选、排序和取值探查；手机号、身份证、银行卡和邮箱在服务端脱敏。二进制仅返回类型与大小，长文本在服务端截断，JSON 安全序列化。前端从未收到明文后再遮挡。

预览策略支持 CRUD：对象/字段白名单、禁止项、敏感字段、脱敏规则、默认排序、分页、文本长度、完整单元格、精确 COUNT、超时、筛选数和最大返回字节。策略修改写入审计日志。
