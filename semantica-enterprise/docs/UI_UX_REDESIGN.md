# 全局 UI/UX 重构说明

## 目标与原则

本次重构以组织级知识平台的日常业务路径为主线，保留全部真实后台能力与既有数据，不改变 FastAPI、Worker、Semantica、DeepSeek Harness 及搜索中间件的职责边界。视觉采用白色工作区、浅灰分层、蓝色品牌强调和紧凑企业表格，减少技术名词直接占用主导航。

所有页面遵循以下约束：

- 页面只呈现完成当前任务所需的信息，解释性内容收敛到副标题、状态提示或详情抽屉。
- 主导航表达业务域，配置项进入配置中心，监控与异常进入运营中心。
- 创建、编辑、删除、测试、同步、重试等按钮继续连接原有真实 API。
- 加载期间禁用提交按钮；取消弹窗和取消文件选择不触发提交校验。
- 页面、会话和检索结果均在各自容器内滚动，不允许内容突破视口后无法访问。
- 以中文状态展示业务含义，同时保留后端枚举作为程序内部协议。

## 信息架构

左侧主导航固定为八个业务域：

| 业务域 | 二级页面 | 主要用户任务 |
| --- | --- | --- |
| 工作台 | 工作台 | 查看知识规模、处理状态、质量、数据源健康与最近活动 |
| 知识资产 | 空间与目录、文档资产 | 组织知识范围，上传、版本化、解析、治理和追溯文档 |
| 数据接入 | 数据源 | 配置连接、测试、同步、调度和查看增量结果 |
| 知识服务 | 智能问答、检索调试、服务开放 | 多轮问答、验证召回排序、使用 REST/MCP/CLI |
| 知识洞察 | 知识图谱、知识分析 | 浏览和编辑图谱，配置规则并运行可追溯推理 |
| 运营中心 | 任务中心、能力检测 | 监控解析/同步/索引任务与多模态依赖能力 |
| 配置中心 | 模型服务、解析策略、加工策略、知识结构 | 统一管理模型与平台级策略配置 |
| 系统管理 | 组织机构、用户管理、角色权限、审计日志 | 管理组织权限和审计记录 |

非管理员不显示配置中心与系统管理，后端权限校验仍是最终权威。

## 原页面迁移映射

| 原入口 | 新入口 | 处理方式 |
| --- | --- | --- |
| 知识空间 | 知识资产 / 空间与目录 | 合并到资产域 |
| 文档 | 知识资产 / 文档资产 | 合并到资产域；任务入口嵌入文档和运营中心 |
| 数据源 | 数据接入 / 数据源 | 保持独立核心入口 |
| 知识检索 | 知识服务 / 智能问答 | 主场景升级为会话工作区 |
| 检索调试 | 知识服务 / 检索调试 | 保留全文、向量、图谱、重排的可解释调试能力 |
| 知识图谱、知识分析 | 知识洞察 | 合并为洞察业务域 |
| 任务、能力检测 | 运营中心 | 汇总运行状态和异常 |
| 模型、解析、切片、抽取、治理、Ontology | 配置中心 | 减少主导航噪声，全部 CRUD 保留 |
| 组织、用户、角色、审计 | 系统管理 | 聚合管理后台能力 |

## 关键交互

### 工作台

- 六项真实指标来自 `/api/v1/dashboard`，包括今日新增、运行/失败任务和治理质量。
- 最近文档、任务与问答均可直接进入真实详情。
- 新建数据源、知识空间、问答和上传文档是高频快捷动作。

### 知识服务

- 智能问答使用固定输入区和内部滚动消息区，浏览器刷新后按会话恢复。
- 检索调试直接请求 `/api/v1/search`，展示通道数、排序、通道分、融合分、重排分与真实片段。
- 页面切换会取消未完成检索，避免异步结果写入已经销毁的页面。

### 配置中心

- 首页按模型、解析、加工、知识结构四类展示真实配置数量和启用状态。
- 二级页保留原有 CRUD、默认配置、启停与连接测试。
- 提交时禁用保存按钮，防止重复创建；API Key 保持不可回显。

### 知识图谱

- 画布、顶部条、图例和检查器统一为白色/浅灰视觉。
- 节点类型颜色、边方向、选中高亮、3D 旋转缩放和节点/边 CRUD 保持不变。

## 视觉规范

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f5f7fa` | 应用背景 |
| `--panel` | `#ffffff` | 卡片、表格和工作区 |
| `--brand` | `#2f6bff` | 主按钮、选中和焦点 |
| `--line` | `#e5e9f0` | 边框与分隔线 |
| `--text` | `#1f2937` | 主要文字 |
| `--muted` | `#667085` | 辅助文字 |

状态采用一致的成功、处理中、失败、警告和停用样式；键盘焦点使用蓝色高可见轮廓。1280、1440 和 1920 宽度下主内容自适应，窄屏下侧栏和多列卡片自动收敛。

## 验收清单

- 八个业务域及其二级页面可通过导航和浏览器前进/后退恢复。
- 工作台指标和活动均来自真实接口。
- 配置中心与系统管理只向管理员显示。
- 问答、检索结果、表格和长详情可滚动访问。
- 图谱为白底且节点、边编辑能力不受影响。
- 弹窗取消不触发校验；提交时不可重复点击。
- 常见桌面分辨率无非预期横向滚动。
- Docker 重建与保留卷重启后页面、会话和数据保持可用。
- 浏览器控制台无未处理错误。
