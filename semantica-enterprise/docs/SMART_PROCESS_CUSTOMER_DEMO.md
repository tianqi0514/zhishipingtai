# 国联集团“智慧流程中枢”客户演示脚本

## 1. 演示目标

本脚本用于演示“传神智库”如何把集团制度、项目材料、业务台账、流程接口、风险事件和对象存储内容，统一沉淀为可治理、可检索、可关联、可问答的组织级知识底座。

演示知识空间：`国联集团·智慧流程中枢演示库`

建议时长：30 分钟；压缩版约 15 分钟。

演示主线：

> 建立独立知识空间 → 多渠道接入 → 自动解析与治理 → 三路检索 → 知识图谱 → 多轮智能问答 → 引用核验

## 4. 30 分钟完整演示流程

### 4.1 开场与空间隔离（2 分钟）

操作：

1. 登录“传神智库”。
2. 在页面顶部的知识空间选择器中选择“国联集团·智慧流程中枢演示库”。
3. 进入“工作台”。
4. 指出最近文档、任务动态和统计均随当前空间联动。

讲解话术：

> 我们先选择一个独立的业务知识空间。空间不只是页面筛选条件，它同时约束文档、数据源、加工任务、图谱、检索和问答的权限范围。后续建设不同子企业或部门知识库时，可以复用同一底座，同时保持数据隔离。

验收点：

- 页面顶部持续显示当前演示空间。
- 切换模块后空间不丢失。
- 其他空间的文档和数据源不会混入列表。

### 4.2 多渠道知识接入（4 分钟）

操作：

1. 进入“输入接入 → 数据源”。
2. 依次查看以下数据源：Web、REST API、RSS、Sitemap、本地目录、S3/MinIO。
3. 打开“演示·流程实例 REST API”，展示连接配置、连接状态、同步记录和增量游标。
4. 点击“测试连接”；确认返回成功。
5. 打开最近一次同步记录，展示真实任务状态和同步结果。

讲解话术：

> 组织知识并不只在上传文件里。平台把网页、业务接口、订阅源、共享目录和对象存储统一纳入数据源管理。每个来源都具备连接测试、手工同步、定时同步、增量游标、版本创建和失败重试，接入结果继续走同一套知识加工链路。

验收点：

- 数据源卡片类型、状态、知识空间和最近同步信息正确。
- “测试连接”和“同步”调用真实后端，不是装饰按钮。
- 重复同步未变化内容时应显示 `unchanged`，不重复创建版本。

### 4.3 多格式文档与自动治理（5 分钟）

操作：

1. 进入“知识资产 → 文档资产”。
2. 展示 MD、XLSX、DOCX、PDF，以及由数据源同步形成的 CSV、JSONL、EML、JSON 和网页文档。
3. 打开“关键流程及合规控制节点梳理表”，查看解析元素、切片和结构位置。
4. 打开“合规体系数字化项目建设报告”，查看自动摘要、分类、标签、关键词和质量评分。
5. 打开“招标公示”，指出其为扫描 PDF，展示 OCR 后内容和页码溯源。
6. 进入文档内的任务区域，展示真实阶段、百分比和耗时。

讲解话术：

> 接入后不是把文件作为附件保存。平台复用语义建模能力，把不同格式统一转换为可追溯的内容元素，再执行切片、实体关系抽取、质量分析、全文索引、向量索引和图谱发布。摘要与分类属于治理画像；页码、工作表、结构路径和解析器信息则保证每条知识都能回到原始依据。

验收点：

- 不同格式文档均为已发布状态。
- 文档详情存在真实 ContentElement 和 Chunk。
- 治理画像存在确定性质量指标；模型治理部分若降级会明确提示，不影响已解析内容。

### 4.4 知识图谱（4 分钟）

操作：

1. 进入“知识洞察 → 知识图谱”。
2. 搜索“智慧流程中枢”。
3. 定位并选中节点。
4. 展开与“上会立项”“采购申请”“合同签订”的关系。
5. 选中一条“贯通”关系，在右侧查看关系类型、置信度和来源类型；随后在三路检索的图谱命中中打开对应真实证据片段。
6. 再搜索 `GL-SP-2026-002`，展示其“触发 → 黄色超时预警”的关系。

讲解话术：

> 全文和向量检索解决“内容在哪里”，图谱进一步解决“对象之间是什么关系”。这里的关系带有知识空间、来源片段和发布版本，不是脱离证据的可视化。图谱关系也可以进入混合检索，为问答补充跨片段的关联事实。

验收点：

- 图谱为白底，缩放、旋转、适配和搜索定位正常。
- “智慧流程中枢”至少存在三条“贯通”关系。
- 图谱关系能够进入图谱召回，召回项可打开真实证据片段。

### 4.5 全文、向量、图谱三路检索（5 分钟）

操作：

1. 进入“知识服务 → 知识检索”。
2. 确认检索范围为当前演示空间。
3. 打开全文、向量、图谱三个开关；重排保持关闭，避免未配置重排模型影响演示。
4. 输入：`智慧流程中枢贯通哪些业务阶段`
5. 执行检索。
6. 在检索轨迹中依次查看全文、向量、图谱召回数量、去重、RRF 融合和最终排序。
7. 在召回依据中打开第一条，查看文档、片段、结构位置和召回通道。

预期结果：

- 全文检索有结果：命中“上会立项、采购申请、合同签订”等原词。
- 向量检索有结果：通过语义相似度召回相关流程说明。
- 图谱检索有结果：命中“智慧流程中枢 — 贯通 → 业务阶段”关系。
- 至少一条最终结果同时带有 `全文 / 向量 / 图谱` 三个通道标识。
- 检索轨迹无整体失败；任一可选通道异常时应明确降级而不是返回 500。

讲解话术：

> 三路检索并不是在前端拼三个列表。平台先分别执行全文、向量和图谱召回，再用 RRF 融合、去重并形成统一排序。右侧保留每个通道的得分与执行轨迹，所以用户可以看到答案为什么优先采用某条知识。

补充检索：

| 问题 | 重点验证 |
|---|---|
| `采购估算价达到30万元以上如何确定采购方式` | 制度原文、金额阈值和引用 |
| `GL-SP-2026-002 为什么预警` | 台账、风险事件、邮件和图谱关系交叉召回 |
| `合规体系数字化项目为什么要建设流程平台` | DOCX 项目材料的语义召回 |

### 4.6 DeepSeek Harness 多轮智能问答（7 分钟）

操作：

1. 进入“知识服务 → 智能问答”。
2. 打开预置会话“客户演示｜智慧流程中枢三轮问答”；如需现场演示流式过程，也可新建会话。
3. 确认检索范围和高级选项默认可见，空间只选择当前演示库。
4. 查看右侧“执行过程”“检索轨迹”“召回依据”三个页签。
5. 依次提问以下三轮问题。

第一轮：

> 请只依据当前知识空间回答：智慧流程中枢一期贯通哪些业务阶段？

预期：回答上会立项、采购申请、合同签订，并带可点击引用。

第二轮：

> 其中流程实例 GL-SP-2026-002 为什么触发预警，责任部门是谁？

预期：结合上一轮上下文，回答该实例因采购需求审批节点超时而触发黄色预警，责任部门为数字赋能中心，并引用台账、风险事件或督办通知。

第三轮：

> 结合集团本部采购实施细则，采购估算价达到30万元以上应如何执行？请附引用。

预期：说明达到 30 万元以上应按集团采购管理制度组织实施；回答以制度原文为依据，不凭模型常识补写。

重点展示：

- “已思考 N 秒”来自真实 Turn 时间戳。
- 执行过程显示 Agent 实际调用知识检索、读取片段、整理引用和生成回答。
- 检索轨迹显示真实查询语句、空间范围、三路数量、融合与耗时。
- 点击回答引用后，右侧自动定位对应召回项，并能打开真实片段。
- 刷新页面后，会话、回答、引用和轨迹仍存在。

讲解话术：

> 智能问答不是一次大模型调用。DeepSeek Harness 负责多轮 Agent Loop、工具选择、流式事件、取消与恢复；知识平台继续负责身份、空间权限、混合检索和片段访问。右侧展示的是可核验的工具与检索过程，不展示也不伪造模型私有思维链。

### 4.7 收束（3 分钟）

建议总结：

> 这套演示形成了一条完整业务闭环：知识从多种媒介和系统进入平台，经统一解析、治理与发布后，同时供全文检索、语义检索、图谱关联和 Agent 问答使用；每条结果可回到文档、页码、结构位置或数据来源。后续应用场景不需要重新建设知识处理链，只需要通过 REST、MCP 或 Agent 工具按权限调用这个知识底座。

## 6. 现场风险与降级方案

| 风险 | 现场处理 |
|---|---|
| 云端 LLM 响应较慢 | 打开已持久化的三轮演示会话；本地全文、BGE 向量和 FalkorDB 图谱检索仍可继续演示 |
| 某一检索通道暂时不可用 | 展示右侧降级 Warning；继续使用其他可用通道，不刷新或反复提交 |
| 浏览器缓存旧页面 | 强制刷新一次，再重新选择演示空间 |
| 数据源 fixture 未启动 | 执行 `docker compose --profile demo up -d source-fixture`，只重测连接，不重新加工所有资料 |
| 页面误切换到其他空间 | 使用顶部知识空间选择器切回“国联集团·智慧流程中枢演示库” |
| 现场需要临时提问 | 优先使用本脚本中的问题；遇到材料无依据的问题，接受系统明确提示“证据不足”，不要引导模型猜测 |

## 7. 演示纪律

- 不在现场展示任何 API Key、数据库密码、对象存储 Secret 或内部服务 Token。
- 不把补充 fixture 描述成客户生产数据。
- 不承诺材料中没有依据的业务结论。
- 不在演示前删除 Docker Volume 或重新初始化平台。
- 不在正式演示时批量重跑全部语义建模任务。
- 现场新增测试对象时统一使用“演示”前缀，演示后再清理。
