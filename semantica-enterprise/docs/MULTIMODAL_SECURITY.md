# 多模态安全边界

## 输入安全

- 扩展名、声明 MIME 和 Magic Bytes 交叉校验；路径只使用清洗后的文件名。
- 媒体按图片/音频/视频分别限制上传大小，策略另有限制时长、文件大小、帧数和任务超时。
- ZIP/邮件附件沿用安全解包的路径穿越、数量、总大小、压缩比和递归层级限制。
- ffmpeg 使用参数数组、`-nostdin` 和受控时间/滤镜，不执行用户提供的命令或表达式。

## 模型与提示注入

画面、字幕、OCR 和 ASR 均是不可信数据，不会拼接成系统指令。Kimi 只接收平台固定的证据提取协议；输出必须通过严格 JSON Schema。文档中的“忽略系统指令”、链接、密钥请求或工具调用文字只作为待检索内容，不能改变 DSH 工具权限。

## 权限和密钥

- 所有媒体 Profile、时间线、帧、缩略图、原媒体 Range 和重处理接口先校验租户与知识空间权限。
- Harness 不接触对象存储和模型密钥；它只调用带短期最小权限凭据的 FastAPI Knowledge Tool。
- Vision API Key 不写策略快照、任务输入、ContentElement、审计详情或模型事件。
- 云处理必须显式允许；本地策略不能回退到云模型。

## 数据生命周期

临时文件位于任务私有目录，任务结束自动删除；帧和缩略图在 MinIO 使用租户/空间/文档/版本/运行分层对象键。策略历史、模型引用、调用时间、结果 Hash 和失败原因可追溯。删除策略不会破坏历史版本；重处理不物理删除被 Chunk 引用的元素。
