## 问题与修复

- 空空间无法先准备资料、解析未索引被当作空成功：现在允许真实 ContentElement 抽取，空解析失败，不伪造知识发布。
- Provider 返回结构与资产 Schema 不一致：统一严格类型，并保留实际请求与修正轨迹。
- 最终上游检查新增 LLM 溯源修复：源码锁定到 6d7364d，导入、结构化输出跟踪、请求级用量及成本传播通过 37 项离线合约；未引入其 CI 的已知失败豁免。
- 空 Fact 可确认、数值保存为字符串、计算输出要求人工填写：增加输入类型与空值检查，输出由实际计算产生。
- 计算无反馈、四个按钮重复、同一输入重复计算：统一一个依赖顺序批量计算入口，显示实际结果，保持幂等及原子性。
- DSH 插件地址类型、API Base 缺失、未选写作图谱仍强制查图谱：修复正式插件与运行配置，未选择图谱真实显示不可用，不制造假快照。
- 已采用费用方法没有进入报告生成：章节工作包、执行和质量校验统一使用本文采用的资产发布版本。
- 章节切换沿用其他文章 ID 导致 404：上下文未就绪时不请求旧文章，组件及浏览器回归通过。
- 普通报告重复计算卡片、表格影响难读：普通段落/金额表替代冗余卡片，弹窗逐项列出金额。
- Plate 正文列表双重圆点：移除 Slate 外层重复 list-item 样式，由真实列表项单独显示标记；保留缩进与有序列表起始编号，组件回归通过。正文标明中文并使用严格换行；少数引用后的句号仍可能孤立换行，尚未完成这一细节的排版收口。
- 数字替换可能误改换算常数：生成时登记有语义、单位、Fact/Run 版本的位置；无法唯一绑定时只能人工核对，不做全文数值替换。
- 导出可能采用其他文章最新计算：依据当前文章实际绑定筛选 Fact 和计算运行。
- 导出文件中文缺字：本机打包 LibreOffice 未加载系统 CJK 字体，配置独立 FONTCONFIG_FILE 与 SAL_FONTPATH 后重新执行实际 API 导出并全页渲染。没有修改用户桌面 Office 或打包运行时；Linux 镜像仍须实际核验字体。

取消影响预览和全部应用已通过真实点击。旧文章撤销在协同自动保存后被 409 拒绝，属于版本保护；本轮不把它记录为撤销已通过。没有为通过测试绕过过期版本保护。
