## 问题与修复

- 空空间无法先准备资料、解析未索引被当作空成功：现在允许真实 ContentElement 抽取，空解析失败，不伪造知识发布。
- Provider 返回结构与资产 Schema 不一致：统一严格类型，并保留实际请求与修正轨迹。
- 空 Fact 可确认、数值保存为字符串、计算输出要求人工填写：增加输入类型与空值检查，输出由实际计算产生。
- 计算无反馈、四个按钮重复、同一输入重复计算：统一一个依赖顺序批量计算入口，显示实际结果，保持幂等及原子性。
- DSH 插件地址类型、API Base 缺失、未选写作图谱仍强制查图谱：修复正式插件与运行配置，未选择图谱真实显示不可用，不制造假快照。
- 已采用费用方法没有进入报告生成：章节工作包、执行和质量校验统一使用本文采用的资产发布版本。
- 章节切换沿用其他文章 ID 导致 404：上下文未就绪时不请求旧文章，组件及浏览器回归通过。
- 普通报告重复计算卡片、表格影响难读：普通段落/金额表替代冗余卡片，弹窗逐项列出金额。
- 数字替换可能误改换算常数：生成时登记有语义、单位、Fact/Run 版本的位置；无法唯一绑定时只能人工核对，不做全文数值替换。
- 导出可能采用其他文章最新计算：依据当前文章实际绑定筛选 Fact 和计算运行。
- 导出文件中文缺字：本机打包 LibreOffice 未加载系统 CJK 字体，配置独立 FONTCONFIG_FILE 与 SAL_FONTPATH 后重新执行实际 API 导出并全页渲染。没有修改用户桌面 Office 或打包运行时；Linux 镜像仍须实际核验字体。

取消影响预览和全部应用已通过真实点击。旧文章撤销在协同自动保存后被 409 拒绝，属于版本保护；本轮不把它记录为撤销已通过。没有为通过测试绕过过期版本保护。

## 文章质量评价

新稿确实来自本次资料与 13 项确认输入，不复制旧报告，仅采用其结构和计算定义。四章齐全，数值、费用表和引用位置一致，缺失土地、融资、设备、用房台账时明确说明，未编造它们为零。

仍是技术验收讨论稿：只覆盖四章，必要性部分缺少真实数量支撑，风险部分有若干重复限定语；没有完整法定可研章节、工程专项附件或正式投资价格依据。程序无重复句、数字校验通过不等于文体达到客户完整样稿质量。继续优化应先补资料、核验章节目标，再处理表达，不用模型补造事实。

## 手工复演

隔离地址：`http://127.0.0.1:8082/miaobi/`。项目选择“科研用房报告生成验收”，打开“科研用房可行性研究报告（完整闭环验收稿）”。当前已采用变更，单价为 5500，总投资为 12705。

1. 准备资料查看 `writing_assets_history.md`（参考）和 `writing_assets_current.md`（业务资料）；源码路径在 `tests/fixtures/`。材料为软件验收构造输入，不是客户事实。
2. 展开“复用历史结构与方法”，查看来源、实际提示词、模型原始输出、四章结构及四个确认费用方法。
3. 创建新文章，选择已经核验的结构与方法，发布并采用。取消确认不会改变目录；采用只创建目录和空输入，不带入历史数字。
4. 填写本次输入，核对名称、单位、用途。点“计算本次结果”检查完整费用链。
5. 在真实知识版本与 DSH 可用时按章生成。不要把没有来源的人工文本当作成功生成。
6. 打开现有完整验收稿，点击“修改输入指标 · 预览正文影响”。例如将当前单价 5500 调为 6000，预期费用链 12000、1200、660、13860 万元。
7. 弹窗核对正文、表格、汇总和风险段落。取消应不变；可以全选，也可以逐项取消。没有登记数字位置的文字不能承诺自动更新。
8. 应用后核对正文、版本记录和其他文章。未选择的位置保留旧文并待核对，不能导出为已全部有效的正式稿。
9. 审校通过后导出 Word/PDF，打开文件检查中文、表格、金额和页码。历史版本仍保留之前 5000/11550。

浏览器实际完成资料上传、模型抽取、定义核验、创建文章、采用取消/确认、计算、影响取消/全部和选择性应用。最终报告的本次输入通过正式 REST 确认，整篇通过真实 DSH SSE 请求生成；这些步骤不混报为全部浏览器输入。
