# 视频抽帧与场景处理

## 处理步骤

1. ffprobe 读取时长、尺寸、编码、音轨和文件大小。
2. 根据固定间隔、FPS、场景或智能模式生成候选时间点。
3. ffmpeg 在候选点解码 JPEG；尾帧不可解码时最多安全回退 0.5 秒并记录 Warning。
4. 限制最长边并生成 360×240 缩略图。
5. 对候选帧计算 SHA-256 与 64 位平均感知 Hash；在配置的汉明距离内去重。
6. 对保留帧本地 OCR，并按配置调用 Vision。
7. 将帧与场景、转写时间区间融合成场景摘要和证据列表。

## 成本控制

`max_frames` 是硬上限；时间范围和最小/最大间隔是第二道限制；pHash 去重是第三道限制。云端调用数只统计实际去重后、视觉成功的帧。上传前的 Probe API 返回时长、估算帧数、是否受上限截断和预计云处理帧数。

## 边界行为

- 无画面视频：保留媒体/音轨结果并警告，不伪造帧。
- 无音轨视频：跳过 ASR，画面流水线继续。
- 黑屏/重复帧：pHash 会显著减少重复调用。
- 竖屏/低分辨率：按最长边等比处理，不拉伸。
- 无明显场景变化：形成一个有界场景；`maximum_scene_seconds` 可将超长场景切段。
- OCR 或 Vision 部分失败：`partial` 策略保留其他证据，并允许按场景重试。

资源验收脚本为 `tests/integration/media_resource_benchmark.py`，真实生成并抽取 1、5、30 分钟视频；模型真实性由独立 ASR/Vision E2E 验证，避免把纯合成压力数据冒充业务准确率样本。
