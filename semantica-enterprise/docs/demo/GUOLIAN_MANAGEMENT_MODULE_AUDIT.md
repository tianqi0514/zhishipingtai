# 国联演示：管理与应用构建模块审计

> 审计日期：2026-09-06
> 数据声明：演示数据，不代表国联集团真实经营数据。

## 结论

配置中心、系统管理、运营中心和应用构建均有真实后端接口，不是纯展示页面。本轮补齐了任务中心的空间权限边界、应用上线准备度的资源关联校验，以及运行反馈不能绕过治理验证直接结案的状态约束；同时建立了与国联演示空间绑定的完整应用调用链。

## 功能与业务闭环

| 模块 | 真实能力 | 演示中的用途 | 本轮验证 |
|---|---|---|---|
| 配置中心 | 模型、路由、解析、媒体、切片、抽取、治理、本体配置 CRUD 与连接/能力测试 | 管理各加工阶段采用的模型和策略 | 接口、Secret 脱敏、当前路由已审计 |
| 系统管理 | 组织、用户、角色、知识空间授权、审计日志 | 展示集团管理员、知识专员和业务用户的职责隔离 | 三类演示角色和空间授权已核验 |
| 运营中心 | 任务状态、阶段、失败重试、能力检测 | 演示长任务真实进度和系统可用性 | `job.read` 与空间过滤已补齐 |
| 应用工作台 | 应用 CRUD、知识供给、不可变发布、场景版本、上线测试、凭据、资源授权、调用审计、运行反馈 | 将知识底座能力交付给集团应用 | 国联专用应用链已真实创建和调用 |

## 本轮修复

1. `/jobs` 列表、详情和重试现在要求 `job.read`。非管理员只看到自己有读取权限的知识空间所关联的任务；无法安全归属空间的后台任务仅管理员可见。
2. 应用准备度改由后端统一计算。场景只有在当前版本引用的同一个知识产品已授权、发布别名可解析、上线测试通过、凭据未过期时才计入就绪。
3. 过期应用凭据明确返回 `expired`，不再显示为“有效”。
4. 知识错误、内容不完整、过期、错误引用和权限类反馈，不能通过通用更新接口直接标记解决；必须转治理、处理完成并使用通过质量门禁的上线测试验证。建议和正向反馈仍可直接归档。

## 当前边界

1. 应用凭据运行时当前公开 `whoami`、场景检索和反馈提交。REST、MCP、CLI 的其他知识能力使用各自现有认证入口；不要把历史凭据 Scope 名称误解为均已有独立应用运行时端点。
2. 当前上线测试验证可重复的检索召回与排序指标，不是生成答案质量或 LLM Judge；页面能力说明与接口均明确该边界。
3. 应用场景类型虽然支持检索、问答、分析和结构化配置，当前应用运行时的已验证端点是场景检索。智能问答和结构化问答由平台现有 DeepSeek Harness/结构化查询链负责，不应在主演示中把场景检索说成完整 Agent 问答。
4. SHACL 能力当前因运行环境未安装 `pyshacl` 不可用，不能纳入现场主演示。
