# 国联集团数据库实时问答演示

> **演示数据，不代表国联集团真实经营数据。** 本演示使用独立 MySQL/PostgreSQL 演示库，不访问平台业务库；Ground Truth 检查 SQL 只用于验收，不能作为问答预设 SQL。

## 1. 为什么需要数据库语义查询

文档和向量索引适合解释“制度怎么规定”，但金额、数量、排名和完成率必须读取实时数据库。平台用本体映射把“采购金额、有效订单、供应商、项目”落到表和字段，再把严格 Plan/IR 确定性编译为只读参数化 SQL。

## 2. 演示链路

```text
只读连接 → Schema 发现 → 实时预览与脱敏 → 本体映射建议
→ 确定性校验 → 管理员激活 → 自然语言问题
→ Semantic Query Plan → 严格 Query IR → 方言编译
→ 只读执行 → 数据引用与 QueryRun 审计
```

Harness 不接触数据库密码，不直接连接数据库，也不能提交原始 SQL。

## 3. 页面操作

1. 数据接入：打开“演示·国联经营数据 PostgreSQL”，点击真实连接测试。
2. 结构发现：查看 16 张业务表、1 个无主键视图、字段、主键、外键和 Schema 版本。
3. 数据预览：打开 `purchase_orders`，按主键稳定排序，分页 20/50/100。
4. 筛选：2026 时间区间、状态、金额区间、NULL；确认参数绑定。
5. 敏感字段：手机号/邮箱显示服务端脱敏；密码/Token 类字段不可预览和筛选。
6. 映射：查看表→本体类、字段→属性、外键→关系；验证后激活版本。
7. 查询测试：输入问题，依次查看 Plan、IR、占位符 SQL、参数摘要、结果和耗时。
8. 智能问答：组合制度口径文档与实时数据库数值，打开两类引用。

## 4. 主演示问题

### 问题一：各单位金额

“2026 年演示数据中，各单位有效采购金额分别是多少，最高是哪家单位？”

预期：数字科技公司 600,000；集团本部 420,000；能源服务公司 380,000；金融科技公司 300,000。最高为数字科技公司。

检查：审批通过、状态过滤、订单主键去重、按单位分组；QueryRun 引用 `org_units`、`purchase_orders`、`approval_records`。

### 问题二：制度+数值

“按照采购制度规定的统计口径，2026 年 NexusOne 相关有效采购金额是多少？”

预期：先检索现行制度得出统计口径，再执行结构化查询；金额为 600,000 元，排除取消和审批未通过订单，同时展示文档引用与数据引用。

### 问题三：目标完成率

“集团 2026 年采购目标完成率是多少，分子和分母分别是什么？”

预期：1,700,000 / 2,100,000 = 80.95%；结果需说明口径和时间边界。

### 问题四：合规异常

“有多少笔订单已经执行但审批尚未完成？”

预期：1 笔；不得混入草稿或已审批订单。

## 5. 20 项 Ground Truth

完整值见 `GUOLIAN_DEMO_GROUND_TRUTH.md` 和机器文件。验收重点包括：SUM/COUNT 区别、COUNT DISTINCT、订单头去重、Top 5、无订单主体、每月金额、最近订单、多对多关系、NULL 和半开时间边界。

执行验证：

```bash
python scripts/demo/verify_guolian_ground_truth.py \
  --postgres-url '从安全环境变量构造的只读 URL' \
  --mysql-url '从安全环境变量构造的只读 URL'
```

命令示例不得将密码写入文档或终端共享画面。当前已分别记录 PostgreSQL 与 MySQL 的 20/20 直连 Ground Truth，并完成平台公开 NL→Plan→IR→参数化 SQL→执行 20/20；演示前仍需用预检确认环境未漂移。

## 6. Schema 漂移备选演示

1. 在隔离演示库增加非敏感字段或改变专门测试字段。
2. 重新发现 Schema，展示 diff。
3. 新增无关字段：Warning，旧映射可用。
4. 删除/不兼容修改已映射字段：映射 stale，阻止查询。
5. 修复并激活新映射；查看版本差异和回滚。

禁止在正式彩排后临时修改数据库；该部分只在 90 分钟技术版演示。

## 7. 安全验收

- 只读账号、只读事务、statement timeout、最大行数/字节和取消。
- 标识符只来自已发现 Schema；值全部参数绑定。
- 拒绝 DDL/DML、多语句、UNION 注入、系统库、未授权表/字段。
- 前端不得先接收明文再遮挡。
- QueryRun 记录映射版本、Schema 指纹、SQL 模板、参数摘要和数据时间，不记录 Secret。
- 结构化结果超限时显示 `truncated`，不能静默截断。

## 8. 当前证据边界

机器 Ground Truth 包含 20 个可执行 `database_check`。2026-09-06 已对独立 MySQL 与 PostgreSQL 分别真实执行 20/20 项直连实算，并以同一组自然语言问题真实完成平台公开 API 的 Plan→严格 IR→确定性方言编译→参数化只读执行 20/20。两库结构发现及无主键对象检查也已重跑；无主键对象只允许预览/查询，不强行稳定物化。上述均为本机当前证据，远端数据库和平台查询链尚未完成独立验证，不能据本说明宣称远端通过。
