# 历史可研资料 → 新稿 → 数值联动：完整演示脚本

更新时间：2026-10-11。对象：上海财经大学大数据研究中心历史可研及已取得的工程标准材料。

主演示约 20—25 分钟。长材料提前真实加工；现场展示已完成的输入、处理和结果，不将历史任务冒充现场实时任务。另附从零操作路径。

## 1. 演示目标与边界

讲清一条业务主线：历史报告中有可复用的文章结构和计算方法，但历史金额不等于新文章事实。系统先提炼、核验、发布结构与方法，再确认本次输入，通过工具计算和 Agent 写作形成新稿。输入变化后，系统沿登记的依赖找到正文和表格中的影响位置，先预览，后应用，保留旧版本。

本次生成的是“投资估算与资金安排复核讨论稿”，不是已经完成专业审核的整本法定可研。金额是敏感性复核假设，不代表上海财经大学实际投资，不作为立项、审批或造价意见。

历史材料取得 14 份，其中客户报告 1 份、规范/指导意见 13 份；不是用户原清单全部 32 项。OCR、历史版次与规范有效性须另行核验，详见 [来源审计](../platform-upgrade/SHUFE_SOURCE_AUDIT.md)。没有取得的全文、未核验的工程结论不拿来演示“已确认”。

本条主线验证全文检索、结构/方法资产和确定性计算。不要把费用公式称为 Semantica 关系推演，不宣称本次已经验收向量、原知识图谱和全部十六类资产的执行能力。

## 4. 20—25 分钟主演示

### 0—2 分钟：从业务流程介绍平台

话术：

> 今天不展示“上传一份旧报告，换个标题就生成新报告”。我们先从材料中找到可复用的结构和方法，再确认本次数据，生成有依据的讨论稿。最后只改一个输入，检查全文哪些位置真正受到影响。

打开知识空间和文档列表，展示历史报告、本次输入和规范材料。查看一份文档的版本、原文预览及加工状态。指出：材料用途会影响处理，样稿用来学习结构与表达，不把旧金额自动当成本次事实。

验收点：空间正确、文件可打开、加工成功与原文对应；页面不是只显示文件名。

### 2—5 分钟：抽取结果与处理留痕

1. 进入妙笔，选择“上财大数据研究中心历史可研提炼”。
2. 打开“大数据研究中心可研写作准备”，选择“准备资料”。
3. 展开“复用历史结构与方法”。
4. 查看十六类入口与真实数量，选择“报告结构”或“计算方法”。
5. 打开具体候选的详情，依次看“资产内容”“来源输入”“实际提示词”“原始输出”。
6. 需要时用“下一页”查看更多候选。不要将当前页 100 条当作整个空间总量。

话术：

> 抽取不只得到摘要。它把可复用结构、输入变量和明确方法分别保存，而且保留了来源原文和实际模型处理记录。模型产物先是候选，需要人工核验。

优先展示原报告的“投资估算和资金筹措章节结构”、基本预备费和项目总投资方法。原文明确支持基本预备费按前两项之和的 5% 计算；这是这个历史项目的方法，不是系统替我们决定一个通用法定费率。

验收点：候选能回到真实文件版本和原文；模型没有为没有来源的类别凑数据。“函数、技能、规则”候选定义不代表它们全部已部署为可执行工具。

### 5—7 分钟：人工治理，而不是盲目接受

切换主演示项目“上财可研投资复核演示”，打开“准备资料 → 复用历史结构与方法”。

1. 打开已核验的三章投资结构：投资估算说明、项目投资估算表、资金筹措。
2. 查看已核验计算方法“基本预备费”和“项目总投资”。
3. 查看 V2 修订：将方法的使用章节映射为上述真实章节；资金章节要求明确“不照搬历史国拨、自筹金额和资金已落实结论”。
4. 查看确认状态、理由、来源及两组验算记录。公式候选不是点一下就成为随意可执行的代码。

如果需要现场确认一个候选：选择另一个尚未确认的报告结构，先打开来源，填写核对理由，再“确认定义”。不要重复确认已经确认的条目，也不要一键接受所有工程条文。主演示已采用的结构与方法不必重新发布。

话术：

> 我们确认的是结构和方法，不是整份旧报告的所有结论。单位、范围、公式和例子都核对之后才采用，后续写作才有稳定依据。

验收点：确认状态真实变化并可刷新恢复；拒绝或关闭详情不会发布资产；已发布版本保留，不被后来的抽取静默覆盖。

### 7—9 分钟：检索与来源定位

打开主演示文章，进入编辑器右侧“来源与计算”，在“检索本章所需依据”输入：

```text
基本预备费
```

点击“检索”。查看命中的本次业务输入片段、标题、通道和正文；样稿不混入业务事实检索。历史方法的原文从资产详情查看。点击正文中的 `[1]` 等引用编号，右侧会读取真实片段、版本和结构位置；也可以展开段落依据中的来源按钮。不需要为了演示检索而额外向正文插入一遍相同引用。

话术：

> 抽取结果不是替代原文。写作时仍可以回到具体片段验证口径，正文依据和原材料之间有实际关联。

检索界面可能显示向量/图谱降级提示。本主线保证的是全文命中，不把降级提示说成“全部通道正常”。没有图谱版本时也不要声称检索用到了关系推演。

验收点：真实返回片段，来源可以打开；不能只显示一个预设回答。

### 9—13 分钟：本次输入、工具计算、真实写作

在“准备资料”查看本次输入文件和三项确认金额：

| 项目 | 初始值（万元） |
|---|---:|
| 建筑安装工程费用 | 10000 |
| 工程建设其他费 | 1000 |
| 原建筑拆除费用 | 200 |

已采用的计算关系：

```text
基本预备费 = (建筑安装工程费用 + 工程建设其他费) × 5%
项目总投资 = 建筑安装工程费用 + 工程建设其他费 + 基本预备费 + 原建筑拆除费用
```

初始结果：基本预备费 550 万元，总投资 11750 万元。

上述是初稿与历史版本的输入；当前就绪稿为 11000/600/12800。不要重新点击计算来“重置”已有文章，不把文件初值讲成当前确认值。

点击“计算本次结果”时，查看实际结果和方法；不是让大模型心算。首次创建文章时，采用结构只产生目录与待确认输入，不直接带入历史金额。

切换“写作”查看已生成的三章初稿与真实生成记录，再“直接编辑”进入 Plate。演示文章须检查：

- 三章完整，金额表有本次输入和工具计算结果。
- 资金安排未确认时只列待核实内容，不复制历史 6000/7032 万元资金或“资金有保障”。
- 没有数量和单价时不编造它们，也不把缺失费用默认写成零。
- 原文、计算和生成记录均可核验。
- 软件操作说明和计划中的测试改值步骤不应进入正式文章；本次输入材料已与操作脚本分离。
- 人工阅读职责与决策语句。本轮程序数字审校通过后，仍发现模型补写了没有依据的部门分工；已在 Plate 中改为待补材料清单。因此“审校通过”不等于事实绝对无幻觉，也不替代人工核验。

话术：

> Agent 负责按章组织文章和调用知识工具，计算工具负责数字。生成的正文仍可人工修改，不是固定 PPT，也不替代业务定稿责任。

已有正文不要为了演示点“整篇重生成”覆盖人工编辑。要现场生成，按附录新建唯一名称的空白文章；已有文章展示真实生成过程记录即可。生成速度依赖当前模型，不承诺固定秒数。

### 13—15 分钟：Plate 与段落依据

1. 点击正文或金额表，查看右侧“来源与计算”的对应依据。
2. 查看确认输入、计算结果和原文引用。正文只用简洁标记，不是大面积彩色数据卡片。
3. 在一个普通空白段落输入 `/`，展示真实块命令；按 Esc 退出，不必增加无关段落。
4. 普通表达可编辑；权威金额的修改走“修改输入指标”，不在正文里手改数字冒充联动。
5. 查看保存状态。存在未保存改动时先保存，之后才预览影响。

话术：

> 写作编辑和依据管理分开：正文保持文章的可读性，依据在旁边。某一段为什么出现这个数，可以找到对应事实、方法和结果。

### 15—19 分钟：修改一个输入，预览全部登记影响

点击“修改输入指标 · 预览正文影响”。

| 当前建安费 | 输入新值 | 预备费变化 | 总投资变化 |
|---:|---:|---:|---:|
| 10000 | 11000 | 550 → 600 | 11750 → 12800 |
| 11000（首轮已应用后） | 12000 | 600 → 650 | 12800 → 13850 |

必须先看下拉框中的当前值，再选择对应行，不能在已经应用过的文章里仍讲“10000 是当前值”。全部单位为万元。

原因示例：

```text
本次敏感性复核：建筑安装工程费用增加1000万元，其他输入和费用口径保持不变。
```

1. 点击“查看影响”，先检查计算链，再看每处正文/表格的前后变化。
2. 核对原始输入、预备费、总投资的传播路径和文章位置。
3. 先点“取消”：正文必须保持原值，正式输入也不能提前生效。
4. 再次预览，演示取消全选、逐项勾选；关闭或取消，仍不改变正文。
5. 最后重新预览并采用全部确定影响。保留必要的核对项；不能把没有登记数字位置的语义提示当成自动改写。
6. 应用后核对：说明中的金额、金额表和汇总一致；其他费 1000、拆除费 200 和原公式 5% 不变。
7. 查看新文稿版本。旧版本仍保留旧金额；其他文章不被静默改写。

本次已实测更新的是两个正文块中的六个金额位置：说明与表格各含建安费、预备费、总投资三处。另有四处范围/口径提示需人工核对，文字不由数字联动自动重写。人工编辑合并段落后，一个旧绑定会提示“正文块已移除”并禁止勾选；这不是仍在正文中的金额，也不能冒充已自动更新。弹窗的直接/间接依赖条数不等于修改段落数。

话术：

> 变化传播依据的是已登记的输入、计算和段落位置，不是把全文中相同的数字替换掉。先看变化、再决定采用。没有绑定的相似文字只能提醒核对，不能承诺自动识别全部影响。

逐项实际应用后，未选内容会保留旧文并标记待核对，这是预期行为；在全部处理完前不要称其为一致的定稿。现场主线先演示勾选与取消，再全部采用，避免带着已知旧金额继续导出。

### 19—22 分钟：审校、版本和 Word/PDF

1. 进入右侧“审校发布”或主流程“检查导出”。
2. 运行审校，处理待核对/失效引用等实际问题，查看定位与依据。
3. 导出草稿 Word 和 PDF，下载并打开。
4. 核对三章标题、金额表、中文、分页、页码和与当前正文一致的金额。
5. 确认这是讨论稿，不冒充正式审批或对外签发。

本轮已通过正式接口下载并逐页检查 DOCX/PDF。Codex 内置浏览器点击下载时报告 `ERR_BLOCKED_BY_CLIENT`，未获得客户端落盘回执；此项不计为浏览器下载通过。客户演示前用常规浏览器完成一次下载预检。若当前客户端拦截下载，可明确说明并打开已经从同一导出任务真实下载的文件，不将它说成刚刚完成的现场下载。

结尾话术：

> 我们复用了历史文章的方法，而没有复用它的旧事实；本次数字由确定性计算产生。写作、修改、依据与版本形成闭环，最后得到能打开、能讨论的正式文档文件。

### 备选 2 分钟：导出写作支撑数据

回到“准备资料”，点击“导出写作数据”。下载 ZIP，检查包含 YAML 和 Markdown 结构说明。它用于查看本文采用的资料、输入、计算和绑定，不是导出模型 Key，也不需要把抽取提示词放进支撑数据包。

## 5. 从零手工复现（提前准备，不计入现场 20 分钟）

1. 平台中新建唯一名称知识空间，或使用已备妥的上财空间。不要删除已有数据来重置。
2. 进入妙笔新建项目，选择该空间，创建唯一名称文章。文章类型选“其他文章”，题目写“科研楼投资估算复核讨论稿 + 日期时间”。
3. 给谁看：项目管理与财务复核人员。写作目的：说明费用口径与敏感性影响，形成讨论稿。时间范围：2026年10月。事项：原科研楼项目投资方法复核。
4. 写作要求复制下方内容。
5. 妙笔“上传资料”上传历史报告，角色“样稿”；另一次上传本次输入 MD，角色“业务资料”。一次多文件上传会统一采用所选材料角色，不混用不同用途。
6. 等待解析和全文加工目标完成，不能仅看“解析已就绪”。妙笔内上传完成后会固定新的资料快照；从智库提前上传的资料，应先完成索引发布再新建项目。在右侧检索“基本预备费”，确认命中本次输入文件后才开始起草。检查“用于本文”选择的是实际需要的版本。已生成文章的旧依据不能静默当成新版本；保留旧稿另建新稿，或逐段核验修改。
7. “复用历史结构与方法”选择历史报告，点击“提炼可复用内容”。完整长文模型抽取可耗时较长，不显示固定假进度。
8. 在“报告结构”找到投资三章，在“计算方法”找到基本预备费与项目总投资。核对 Evidence；需要时修订使用章节和资金章节要求，再确认。
9. 确认两个计算方法时，核验单位万元及两组例子：正常输入产生 550/11750，全部零输入产生零；核对总投资依赖预备费。不要把程序验算当成工程业务批准。
