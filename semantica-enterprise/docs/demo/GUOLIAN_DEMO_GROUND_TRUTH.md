# 国联集团演示 Ground Truth

> **演示数据，不代表国联集团真实经营数据。** 本文是人工可读索引，机器验收以 `demo/guolian/demo_ground_truth.json` 和 `demo/guolian/structured_query_ground_truth.json` 为准。

## 1. 验收基准结构

| 基准 | 规模 | 校验内容 | 权威文件 |
|---|---:|---|---|
| 文档/图谱事实 | 30 条 | 内容、来源、结构位置、版本、实体、关系、治理标记；其中 9 条为图谱种子事实、8 条为规则推演前提 | `demo_ground_truth.json` |
| 文档问答 | 12 题 | 答案要点、来源要求、负向问答；包含扫描采购审批单与数据库记录的交叉核验 | `demo_ground_truth.json` |
| 结构化问答 | 20 题 | 口径、参数、预期值、误差、引用和真实 DB 检查 | `structured_query_ground_truth.json` |

离线严格校验命令：

```bash
python scripts/demo/verify_guolian_ground_truth.py
```

当前明确证据：Ground Truth Schema 与关联完整性单元测试已通过；MySQL 与 PostgreSQL 的 20 个 `database_check` 已分别真实实算为 20/20；同一 20 题还通过了平台公开结构化查询 API 的自然语言问题→Semantic Query Plan→严格 Query IR→参数化 SQL→只读执行链路，结果为 20/20。Ground Truth 检查 SQL 只作为独立 Oracle，不被复制为平台问答预设 SQL。

## 5. ASR 别名治理验收

SenseVoice 对演示音频的直接实测耗时约 5.7 秒、产生 5 个片段；其中“东方智造”被识别为“东方制造”。验收应保留原始 transcript，并执行：

1. 自动治理提出“东方制造”与供应商“东方智造”的别名候选；
2. 业务专员查看音频时间区间和上下文；
3. 人工确认为同一演示主体，标准名设为“东方智造”；
4. 原始 ASR 文本不可覆盖，人工覆盖层可撤销；
5. 使用两个名称检索均能命中，图谱只保留一个标准节点。

以上是目标闭环。当前已验证原始 transcript、时间区间以及通用实体 must-link/cannot-link 和回滚；尚未实现从 ASR 低置信度直接生成实体别名候选的专用待办，因此这组完整五步流程当前不能在主演示中宣称已通过。
