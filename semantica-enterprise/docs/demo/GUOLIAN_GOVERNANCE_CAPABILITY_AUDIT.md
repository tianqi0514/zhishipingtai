## 运行方法

查看真实能力边界，不访问服务：

```bash
python scripts/demo/prepare_guolian_governance.py --dry-run
```

只读检查当前演示空间：

```bash
python scripts/demo/prepare_guolian_governance.py --verify-only
```

执行一次真实治理发布和回滚：

```bash
python scripts/demo/prepare_guolian_governance.py
```

管理员密码只通过安全环境变量传入。脚本不会输出密码、访问令牌或数据库连接凭据。它只匹配编码和名称均正确的唯一演示空间，并且没有任何 DELETE 调用。

## 演示取舍

主演示可以真实操作组织别名、供应商区分、分类、OCR、元数据、关系、跨文档重复治理和回滚。重复治理演示应明确：平台保留两个来源及其历史，只屏蔽选定副本的当前知识投影；如需现场撤销，应演示“选择主文档→发布→按批次回滚”，不要把“保留两份”说成可单独撤销。制度版本与知识过期仍只能展示自动识别到的时间信息和历史标签，不应承诺当前系统已经具备制度谱系、条款差异或到期自动下线。

最终生产镜像重建后已复测治理关联的白底图谱、规则推演、真实来源片段和数据库服务端脱敏，但没有穷举治理工作台的每个按钮、全部 Case 类型和所有回滚组合。三轮完整客户彩排及远端治理验证仍未完成，这些限制不因 API 8/8 通过而消失。
