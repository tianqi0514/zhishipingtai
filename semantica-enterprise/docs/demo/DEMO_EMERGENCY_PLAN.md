# 国联集团演示应急预案

> **演示数据，不代表国联集团真实经营数据。** 应急措施必须诚实显示降级，不能用静态 JSON、预设答案或录屏冒充实时能力。

## 1. 演示前准备

- 本机与测试环境各保存同一 Git commit、迁移版本和演示数据基准。
- 主演示多模态素材提前完成加工；现场只上传一份短 Markdown 或短 PDF 展示真实进度。
- 将 8 个主演示问题及引用在当日环境实测一遍，记录 Query ID/Run ID。
- 预先打开：工作台、演示空间文档、治理工作台、图谱、知识分析、数据库预览、智能问答。
- 保留 `preflight` 输出和本文件，但不在客户屏幕展示 Secret 或开发终端。

## 2. 故障处置矩阵

| 故障 | 现场识别 | 立即动作 | 可以继续展示 | 禁止说法 |
|---|---|---|---|---|
| 在线千问不可用 | 模型测试/Agent 报真实错误 | 停止重复点击；当前没有已验证备用，暂停生成能力 | 文档、图谱、DB 预览和已有证据 | “系统自动切换了”或“已切 Kimi” |
| Kimi 不可用 | 当前 LLM/Vision 测试均失败 | 保持不路由、不切换 | 非生成页面；千问仍可用时不受影响 | 把“已配置”说成“可用备用” |
| 内网 Qwen 不可达 | 连接超时 | 保持停用 | 全部当前在线路由 | 临时启用、把超时说成成功 |
| BGE/Qdrant 不可用 | 向量 Warning | 关闭向量通道，保留全文+图谱 | 语义差异需说明不可演示 | 把全文结果称为向量召回 |
| Vision 不可用 | 帧无视觉描述 | 展示真实 OCR、帧元数据和已加工证据；说明降级 | OCR、ASR、文档能力 | 口述不存在的视觉结果 |
| SenseVoice 不可用 | transcript 为空/任务失败 | 展示媒体元数据和已预处理材料；不现场重跑大任务 | 图片、视频帧、文档 | 编造音频内容或说话人 |
| OpenSearch 不可用 | 全文通道 Warning | 使用向量+图谱 | 其他真实通道 | 整体 500 或隐瞒通道失败 |
| Qdrant 不可用 | 向量通道 Warning | 使用全文+图谱 | 图谱跨源路径 | 把图谱分当向量分 |
| FalkorDB 不可用 | 图谱加载/通道失败 | 使用全文+向量，跳过多跳结论 | 原文证据、DB 数值 | 预设图谱路径 |
| 演示数据库不可用 | 连接测试失败 | 不执行实时数值问答；展示文档口径 | 文档/图谱/多模态 | 用 CSV 快照冒充实时数据库 |
| Agent 超时/429 | turn_failed/warning | 停止、等待配额窗口、重试一次或切预检备用 | 检索调试可单独演示 | 无限重试、隐藏失败 |
| 视频仍在加工 | 任务非终态 | 切换已完成素材或跳到文档治理 | 其他已通过素材 | 假进度或静态帧冒充处理结果 |
| 测试环境不可访问 | HTTP/SSH 失败 | 切换本机 URL，明确当前为本机备份 | 本机全链路 | 声称远端已部署成功 |
| 页面缓存/脚本异常 | Console error、旧资源 | 强制刷新一次；仍失败则切备选模块 | API/CLI 可作为真实替代路径 | 临时改 DOM 或掩盖错误 |

## 3. ASR 名称偏差话术

若页面显示“东方制造”，不要现场改 transcript。说明：

> “这是语音识别的真实原始结果。组织级知识底座不会把模型结果当作绝对事实；系统把它与已有供应商主数据比较，形成别名候选，业务专员确认后标准化为‘东方智造’，同时保留原始转写和操作记录。”

当前没有“ASR 低置信度 → 实体别名候选”的专用待办闭环，因此主演示只保留原始偏差和时间证据，不现场声称已自动形成别名。只有当通用实体列表中真实存在两个候选、且治理入口已在当日预检通过时，才可以用通用 must-link 进行人工确认并验证检索；否则把该步骤列为产品缺口并切换已验证的“国联数科 → 数字科技公司”组织别名案例。

## 4. 时间失控时的剪裁顺序

保留：平台定位 → 多源资产 → 一个治理案例 → 图谱/向量差异 → 一个 DB 数值问答 → 一个 Semantica 推演 → 引用核验。

依次移入问答环节：配置 CRUD、完整 Schema 漂移、图谱临时节点 CRUD、专业 SPARQL、REST/MCP/CLI、所有治理案例、模型详情。不可跳过证据和“演示数据”声明。

## 5. 恢复后动作

1. 保存失败时间、页面、请求 ID、Job/Turn/QueryRun ID。
2. 查看 API/Worker/Harness/中间件日志，先脱敏再归档。
3. 定位根因并增量修复，不关闭测试、不降低断言。
4. 重建受影响服务，重跑受影响层及完整预检。
5. 在 `DEMO_TEST_REPORT.md` 记录问题、修复 commit 和复测证据。

## 6. 对客户的诚实边界

- 远端未验证时说“当前展示本机完整环境，远端恢复后执行同一套独立验收”。
- 云模型故障时说清具体通道，不把降级说成全功能成功。
- 演示数据不是国联真实经营数据；数值的价值在于统计口径、查询安全和可审计链路。
- 任何未实测功能只说设计/当前限制，不承诺已上线。
