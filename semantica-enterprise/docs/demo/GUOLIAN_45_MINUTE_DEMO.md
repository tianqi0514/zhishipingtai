# 传神智库 45 分钟标准演示

> **演示数据，不代表国联集团真实经营数据。** 本脚本是标准客户版，详细话术、问题答案和应急说明见 `GUOLIAN_FULL_PLATFORM_DEMO_SCRIPT.md`。

## 演示节奏

| 章节 | 时间 | 页面 | 重点操作 | 验收锚点 |
|---|---:|---|---|---|
| 1. 定位与空间 | 4 分钟 | 登录、工作台、空间 | 登录、选择空间、查看三角色权限 | 空间联动、刷新登录有效 |
| 2. 多源接入 | 6 分钟 | 文档资产、数据源、任务 | 浏览多格式、上传短 MD、打开 DB Schema/预览 | MD 无 OCR；真实进度；敏感字段脱敏 |
| 3. 知识治理 | 7 分钟 | 治理概览、内容治理 | 制度时间画像、组织别名、缺关系 | 画像差异可见；组织 must-link 和缺关系可发布/回滚；不承诺制度谱系 |
| 4. 语义与图谱 | 5 分钟 | 知识结构、知识图谱 | 看本体、搜索节点、展开路径和来源 | 白底 3D、逐跳 Provenance |
| 5. 规则推演 | 5 分钟 | 分析任务、发现结果 | 试运行供应商风险规则、看证明、发布 | Semantica Run、规则版本、图谱新边 |
| 6. 检索对比 | 4 分钟 | 检索调试 | 仅向量、仅图谱、三路 | 真实通道数、排序、Warning |
| 7. Agent 问答 | 9 分钟 | 智能问答 | 制度追问、DB 数值、图谱路径、多模态、负向问答 | DSH 事件、引用、600k、时间戳、拒绝编造 |
| 8. 开放与总结 | 5 分钟 | 服务开放、审计 | REST/MCP/CLI、调用记录 | 真实调用和权限边界 |

## 页面点击顺序

1. 登录 → 工作台 → 选择 `guolian-enterprise-demo`。
2. 知识资产 → 文档资产 → 上传短 MD（检索+图谱）→ 任务详情。
3. 数据接入 → PostgreSQL → 结构发现 → 数据预览 → 语义映射。
4. 知识治理 → 内容治理 → 制度时间画像 → 组织别名 → 缺失关系。
5. 知识治理 → 知识图谱 → 搜索“东方智造”→ 展开来源。
6. 知识治理 → 规则推演 → 分析任务 → 发现结果 → 证明链。
7. 知识服务 → 检索调试 → 六种模式中至少展示三种。
8. 知识服务 → 智能问答 → 完成 5 个主问题并打开引用。
9. 知识服务 → 服务开放 → 展示当日已验证的 REST/MCP/CLI。

## 五个主问题

1. “《集团本部采购实施细则（2025演示现行版）》主要适用于哪些单位？”
2. “它对供应商准入有哪些要求？”
3. “按照采购制度规定的统计口径，2026 年 NexusOne 相关有效采购金额是多少？”
4. “东方智造的交付延期会影响哪些项目和责任部门？请说明完整路径。”
5. “项目例会中提到什么风险，视频中哪个建设阶段可能受影响？”

如时间允许，加负向问题：“国联集团明年的实际利润目标是多少？”答案必须明确当前空间证据不足。
