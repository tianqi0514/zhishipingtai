# 国联集团多模态知识演示

> **演示数据，不代表国联集团真实经营数据。** 多模态结果必须来自真实 OCR、ASR、抽帧或 Vision 调用，不得用旁白稿、静态文本或人工描述冒充模型输出。

## 1. 演示目标

证明平台把扫描件、图片、录音和视频转换为统一 ContentElement，并保留原页、原图、关键帧和时间区间，使其能够治理、检索、引用和形成关系。

## 2. 素材与预期

| 媒介 | 文件 | 真正处理 | 用户可见输出 |
|---|---|---|---|
| 扫描 PDF | 供应商现场评估记录-扫描件.pdf | OCR、版面、置信度 | 文本、页码、原页、低置信度告警 |
| 架构图 | 项目总体架构图.png | OCR 与 Vision 分开 | 图片文字、组件关系描述、图片引用 |
| 表格截图 | 供应商评估表截图.png | OCR/视觉、表格质量 | 风险字段和原图定位 |
| 音频 | 项目例会.wav | SenseVoice ASR | transcript、时间区间、模型信息 |
| 视频 | 项目介绍.mp4 | ffmpeg 音轨、ASR、抽帧、帧 OCR/Vision | 54 秒时间线、关键帧、视觉描述和引用 |

## 3. 现场操作

### 3.1 图片与扫描件

1. 选择国联演示空间，进入文档资产。
2. 打开扫描 PDF，确认解析详情显示 OCR，不是普通文本伪装。
3. 点击低置信度位置，查看原页并修正供应商名称/金额；发布后检查审计。
4. 打开架构图，分别查看“OCR 文本”和“视觉描述”。
5. 提问：“这张项目架构图展示了哪些系统组件，它们之间是什么关系？”
6. 点击引用回到图片/帧，而不是只显示生成答案。

### 3.2 音频

1. 打开 WAV 的 transcript 时间线。
2. 播放/定位包含“延期十个工作日、数字化管理部协调替代方案、风险管理部持续跟踪”的片段。
3. 提问：“项目例会中提到的交付风险是什么，哪个部门需要采取什么行动？”
4. 验证回答引用含时间区间，不伪造说话人身份。
5. 对“东方制造”执行别名治理，标准化到“东方智造”，保留原 ASR 文本。

2026-09-06 本机实测证据：该 WAV 时长约 65.7 秒，SenseVoice 直接调用约 5.7 秒；平台媒体任务状态为成功，生成 5 个带文本和时间区间的转写片段、6 条时间线。最终 DSH 多轮服务链已经通过；音视频播放器、人工修正和所有时间点跳转按钮仍未做浏览器穷举。

### 3.3 视频

1. 上传或打开 54 秒 MP4；策略选择固定 5 秒或 10 秒，按当前媒体策略展示真实配置。
2. 查看阶段：预处理 → 音轨/ASR → 抽帧 → OCR/Vision → 持久化 → 知识加工。
3. 检查抽帧数量、关键帧时间、视觉调用次数和总耗时。
4. 提问：“视频介绍的核心模块有哪些，哪个阶段可能受供应商延期影响？”
5. 打开引用，定位到系统架构、风险路径或价值页关键帧。

## 4. 预期业务价值

- OCR：扫描制度和表单不再只是附件。
- Vision：识别图中组件和关系，而不只是抄出文字。
- ASR：会议决定可按时间区间检索和追溯。
- 视频时间线：把语音、帧文字和视觉描述统一到时间轴。
- 治理：模型识别偏差不会静默成为正式事实。

## 5. 必须验证的边界

- Markdown、TXT、JSON、CSV 等直接文本/结构化文件不得进入 OCR。
- Vision 未配置/失败时只保存真实 OCR 和帧元数据，并显示 `not_configured`/失败告警。
- ASR 未配置/失败时不能生成虚假 transcript。
- 音视频引用必须包含时间区间；图片/扫描 PDF 引用必须可打开原图/页。
- 不根据音色猜测说话人身份。
- 云端 Vision 会发送帧内容，演示前应说明数据出域边界。
- 任务百分比必须按真实阶段推进，长时间调用不能停在伪造固定值。
