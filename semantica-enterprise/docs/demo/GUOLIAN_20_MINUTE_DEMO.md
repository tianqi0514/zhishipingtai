# 传神智库 20 分钟高层演示

> **演示数据，不代表国联集团真实经营数据。** 只展示当日预检通过的真实能力。

## 演示目标

让管理层在 20 分钟内理解：平台把集团分散的文档、数据库和多模态内容治理为统一知识供给，并用图谱、规则和实时查询支撑员工与智能体。

## 固定演示问题

1. “按照采购制度规定的统计口径，2026 年 NexusOne 相关有效采购金额是多少？”
2. “东方智造的交付延期会影响哪些项目和责任部门？请说明完整路径。”
3. “项目例会里提到了什么风险，视频中哪个阶段可能受影响？”

## 不在主线展开

完整配置 CRUD、Schema 漂移、专业 SPARQL、全部治理 Case、模型细节、应用构建、权限负向测试移入 45/90 分钟版或问答。即使压缩时间，也不能跳过“演示数据”声明和引用核验。

## 应急剪裁

- LLM 故障：展示检索/图谱/DB 预览，明确问答不可用。
- Vision 故障：只展示真实 OCR/ASR/帧元数据。
- DB 故障：不以 CSV 冒充实时数据。
- 测试环境故障：切本机并明确说明；当前远端仍待验证。
