## 2. 演示动作

1. 以知识管理员进入“配置中心 → 模型服务”，只展示名称、类型、状态和最近测试，不展开 Secret。
2. 打开“模型路由”，确认四个 LLM 场景解析到在线千问，Vision 指向千问视觉配置，Embedding/ASR 指向本地 BGE/SenseVoice；Reranker 显示未配置降级。
3. 点击在线千问“连接测试”，后台发起真实最小请求；连接失败不得显示绿色成功。
4. 展示 Kimi 当前测试失败且未路由、内网 Qwen 停用，解释“配置保留不代表可用，更不代表加入路由”。
5. 在智能问答右侧执行过程核对 Agent 工具事件；不要展示模型私有思维链。

## 3. 建议参数

| 参数 | 演示值 | 原因 |
|---|---:|---|
| temperature | 0–0.1 | 结构化输出和现场答案稳定 |
| max_tokens | 8192 或按场景限制 | 支持长依据但避免无界生成 |
| enable_thinking | false | 降低延迟，且不把私有思维链误作执行轨迹 |
| timeout | 120 秒 | 兼顾云端波动和现场等待 |
| retry | 2 | 处理短暂网络故障，避免无限重试 |
| concurrency | 4 | 演示环境资源可控 |

## 4. 安全边界

- API Key 只由 FastAPI/Worker 从加密配置读取；浏览器、Harness Session Event、QueryRun、日志和文档不得包含明文。
- Harness 不保存平台 Key；通过受控协议请求模型和知识工具。
- 显式选择的云模型意味着相关请求内容可能离开内网。现场需说明发送范围，并在生产设计中按数据分类决定本地/云端模型。
- 关闭 `enable_thinking` 不影响平台展示真实 Turn、Step、工具选择、检索、查询、引用和耗时。
- 失败切换只有在代码真实实现、审计和测试后才能称为“自动故障转移”；当前演示按管理员显式切换说明。
