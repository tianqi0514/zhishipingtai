## 6. 治理验收边界

真实通过的 8 类演示治理场景包括组织标准名、供应商区分、分类标签、OCR 内容、画像元数据、带来源关系、跨文档重复以及发布/回滚链路。重复治理可比较两个当前版本的 A/B 内容，选择保留两份，或选择主文档并屏蔽副本文档当前版本的 Chunk/Fact；随后真实重发检索和图谱，合并批次可回滚并重开待办。

准确边界：该能力不物理删除 Document 或历史版本；“保留两份”当前没有独立撤销入口；A/B 对比不等同于完整制度谱系、条款级差异或按生效期自动切换。以下仍未闭环：

- 跨文档制度谱系、条款级差异和按生效期自动切换当前版本。
- 过期知识的完整自动下线工作流。
- 非结构化文档统一 PII 发布阻断。
- ASR 低置信度实体到专用别名治理待办的完整闭环。
