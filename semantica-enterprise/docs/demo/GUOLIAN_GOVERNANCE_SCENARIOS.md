# 国联集团演示治理场景

> **演示数据，不代表国联集团真实经营数据。** 自动治理结果是建议或加工输出；人工治理形成可追溯覆盖层，不能静默改写原始内容。下表同时包含产品目标与当前能力，主演示只能使用标为“通过”的闭环；实测详情见 `GUOLIAN_GOVERNANCE_CAPABILITY_AUDIT.md`。

## 1. 演示主张

自动能力降低整理成本，业务人员负责确认组织语义和风险边界。治理发布后应真实影响当前检索、实体归一化和图谱；回滚后恢复上一有效版本，同时保留历史操作。

## 3. 推荐主演示：三步闭环

### 3.1 制度版本（当前只演示识别与画像，不宣称完成版本切换）

1. 进入“知识治理 → 内容治理”，分别打开 2023 和 2025 演示材料。
2. 展示自动画像识别出的有效区间、历史标签与口径差异。
3. 演示画像字段人工修正及回滚。
4. 明确说明：跨文档制度谱系、条款级差异和按生效期自动切换当前检索尚未形成完整产品闭环，不在现场承诺。

### 3.2 组织别名

1. 在图谱中定位“数字科技公司”和“国联数科”。
2. 查看两端类型和已有来源，由业务人员确认标准主体。
3. 建立 must-link 并发布，观察关系投影改写。
4. 按批次回滚，验证两个节点恢复且审计历史保留。

### 3.3 缺失关系

1. 打开“关系缺失”任务，来源为项目 JSON。
2. 补充 `NexusOne — 用于 → 智慧流程中枢项目`。
3. 预览影响并发布新图谱版本。
4. 运行图谱检索和供应商风险推演，确认路径新增。
5. 撤回治理发布，确认边从当前图谱消失、历史仍在。

### 3.4 重复文档

1. 打开跨文档重复待办，对比 A/B 两份当前版本内容、来源、Hash 和相似度。
2. 解释“保留两份”与“选定主文档”的区别：前者只关闭建议，后者屏蔽副本当前版本的 Chunk/Fact。
3. 选择主文档并发布，等待全文、向量和图谱投影真实重发。
4. 验证副本不再混入当前知识供给，但 Document、来源和历史版本仍可追溯。
5. 按合并批次回滚，确认 Chunk/Fact 恢复且待办重新打开。

现场若需要演示撤销，应选择第 2 种路径；“保留两份”当前没有独立撤销入口。

## 4. 自动与人工边界

自动：摘要、分类、标签、语言、完整性、重复、OCR/ASR 质量、过期、实体/关系抽取、归一化/冲突建议和质量评分。

人工：确认当前版本、修正分类标签、补元数据、合并/拆分实体、修正/补关系、确认低置信度、决定发布和撤回。

新自动任务不得覆盖人工确认。它只能产生新建议，并说明与当前人工覆盖层的差异。
