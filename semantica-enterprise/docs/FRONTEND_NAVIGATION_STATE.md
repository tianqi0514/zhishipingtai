# 前端导航与状态模型

## 状态分层

| 层级 | 示例 | 生命周期 |
| --- | --- | --- |
| 身份状态 | Token、当前用户 | 登录会话 |
| 平台状态 | 配置中心、系统管理 | 不受知识空间切换影响 |
| 空间状态 | `activeSpaceId` | 按用户持久化，切换后联动所有空间级页面 |
| 页面状态 | 文档筛选、数据源详情、治理页签 | 每个视图独立保存 |
| 请求状态 | AbortController、请求序号 | 每次导航创建，离开页面立即取消 |
| 一次性反馈 | 新空间、新上传成功横幅 | 消费后清除，刷新不重复显示 |

## 导航生命周期

1. 解析 Hash 并确认用户是否有权进入。
2. 终止上一页面请求、计时器、SSE 和图谱实例。
3. 保存上一页面滚动位置。
4. 立即渲染目标页面骨架。
5. 并行读取所需资源；公共资源通过缓存复用。
6. 仅当请求序号仍是当前页面时写入 DOM。
7. 恢复页面状态与滚动位置。
8. 记录耗时、请求数、缓存命中和取消信息到诊断历史。

前进、后退和刷新都走同一生命周期。旧请求即使晚到也不能覆盖新页面。

## 空间切换

空间切换会：

- 更新本地持久化的当前空间；
- 清除旧空间的页面状态和相关缓存；
- 取消旧空间请求；
- 重新加载当前业务页面；
- 保留平台级页面的独立状态。

新建空间成功后直接完成这套切换，并导航到 `#documents`。这保证文档上传、数据源、治理和知识服务都天然处于新空间上下文。

## 诊断入口

开发环境可在控制台读取 `window.__chuanshenDiagnostics`，查看最近导航耗时、请求数量、缓存命中、当前请求序号、活跃计时器和图谱生命周期。诊断信息不包含 Token、API Key 或知识内容。
