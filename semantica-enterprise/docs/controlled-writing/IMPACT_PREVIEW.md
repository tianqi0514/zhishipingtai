# 影响预览与应用

事实修改首先生成候选新值，执行校验、公式重算、Semantica 重推演和依赖闭包，再生成不可变 ImpactPreview。此时正文完全不变。

预览区分：原子事实、重算指标、推演结论、确定性文本替换、需 Agent 重述、表格/摘要/附件、疑似影响、人工覆盖、定稿和其他文章；每项给出前后值、原因、影响类型和传播路径。

用户可取消、全选、仅选确定影响或逐项选择。提交创建新 Fact/ComputationRun/InferenceRun 和新文稿版本；未选项保留旧投影并标记 stale。人工覆盖不静默更新，定稿只创建新草稿。预览指纹过期即拒绝；幂等键防重复应用；回滚同样创建新版本和审计事件。
