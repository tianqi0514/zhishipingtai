# 安全边界

- 所有写作、语料包、证据和导出接口校验租户、项目角色和对象归属。
- 插件不连接数据库、中间件或物理业务表；凭据不进入工具结果或模型上下文。
- 上传限制在配置的安全根目录，防路径穿越；HTML/Markdown 输出转义。
- 文档内容是不可信数据；“忽略系统提示”等只作为 Evidence 正文。
- Evidence、Fact、Chunk ID 均校验归属；过期预览、跨项目和跨租户操作拒绝。
- 公式采用受控定义，不能执行任意代码；Semantica 规则经过 Schema 校验。
- 日志记录 ID、状态和摘要，不记录 Secret 或无必要的完整敏感原文。
- 理论上无法保证模型绝对无幻觉；通过绑定、闸门和人工确认阻止无依据内容进入正式稿。
