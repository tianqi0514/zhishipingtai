# 可控推演写作产品设计

## 目标

产品把“资料理解、确定性计算、规则推演、专业表达”拆开处理。用户在 DeepSeek Work 上传材料并发起写作，传神智库保存权威对象和不可变版本，Semantica 生成有证明链的推导，写作 Agent 只负责候选抽取、目录建议和语言组织。

主流程为：上传材料 → 真实解析 → 语料包 → 关键事实确认 → 继承 Diff → 计算和推演 → 按章生成 → Chunk 绑定 → 质量闸门 → 事实变更预览 → 选择性应用 → 新版本 → 导出。

## 用户可见对象

- 项目：当前事项的材料、事实、规则和文稿容器。
- 语料包：历史样稿的结构、文风、证据和脱敏骨架快照。
- 事实：当前项目采用的值、单位、时间、范围和证据。
- 报告：由稳定 Chunk 组成，可编辑但受控值不能当普通文本静默修改。
- 影响预览：事实变化后、正文变化前的不可变差异清单。

## 产品约束

- 历史样稿借形不借值；Skeleton 不向 Agent 暴露历史数值。
- 模型不能确认 Fact、计算正式数值、决定传播闭包或提交版本。
- 应用影响前正文不变；未选择项保留旧值并标记 stale。
- 历史事实、运行记录和文稿版本不可变。
- 精确数字、正式职责和推演结论没有权威绑定时不能通过定稿闸门。
