# DeepSeek Work 插件

插件是受限 HTTP 适配层：使用严格 Schema 注册传神工具，文件只能来自允许目录，长任务返回 job/run ID，并通过轮询或 SSE 获取终态。插件使用仓库外、权限受限的凭据文件换取短期 Token，不向 Agent、工具参数或页面暴露凭据。

工具覆盖资料加工、语料包、五层事实治理、写作图谱发布、继承 Diff、计算/推演、项目/文稿、逐章生成、Chunk 依据、编辑 Diff、事实变更预览/应用/回滚、版本比较和导出。

当 DeepSeek Work 没有自定义卡片扩展点时，工具返回结构化 Markdown 摘要和原始 JSON 折叠信息；复杂预览提供受权限保护的平台详情入口。任务创建不等于任务完成。
