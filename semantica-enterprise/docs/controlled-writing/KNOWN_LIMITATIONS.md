# 已知限制

- 未绑定但语义相似的正文只能列为疑似影响，不能保证自动找全或自动修改。
- 未治理历史样稿会保守移除全部数字；日期、页码也可能成为待对齐槽位，治理后应改用显式指标绑定。
- 语义字段对齐只生成候选，必须人工确认；当前不执行无人值守本体合并。
- DeepSeek Work 当前工具结果以结构化 Markdown 为主；复杂 Plate 交互继续在妙笔详情页完成。
- 自动审校不能替代业务、法律、造价或行政审批。
- 外部模型限流、网络和公开标准有效性属于运行依赖，预检失败时不得宣称生成完成。
- 当前 DeepSeek Work 版本启动时偶发 WebSocket 连接重试 Warning；本轮调用能够自动恢复并正常终态，若演示网络抖动应等待连接恢复后再发起长任务。
- 本轮双向 Diff 的最新浏览器终验采用只读项目上下文；整篇报告的对象级传播、导出和版本由服务器 API 全链路验收，浏览器侧沿用此前完整报告与单章真实写作回归，没有再次制造一份整篇长报告。
- Codex 随附的隔离 DOCX 渲染器缺少 CJK 字体；正式 DOCX 已用系统 LibreOffice 真实渲染确认中文正常。部署到新的导出节点时仍需安装可用中文字体并执行逐页渲染验收。
