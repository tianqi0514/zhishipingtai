# 结构化数据浏览器测试报告

## 环境

- 日期：2026-09-01
- 地址：`http://localhost:8080/`
- 浏览器：Codex 内置真实浏览器
- 实际视口：1280×720
- 数据源：`结构化经营数据验收库`
- 数据库：隔离 PostgreSQL fixture
- 浏览器控制台错误：0

浏览器操作直接点击前端并由 FastAPI、数据库和 DeepSeek Harness 处理，不以 API 脚本代替浏览器验收。

## 点击结果

| 流程 | 实际操作 | 结果 |
|---|---|---|
| 重启恢复 | 完整停止/启动服务后刷新页面 | 登录态、11 个会话、消息、事件和引用恢复 |
| 数据源详情 | 数据源列表点击“结构化经营数据验收库 → 详情” | 显示 9 个对象、53 个字段、Schema V1、映射 V2 |
| 数据预览 | 点击“数据预览 → customers” | 返回 4 行实时数据库数据 |
| 无主键表 | 点击 `activity_log` | 返回 2 行并显示稳定分页警告 |
| 脱敏 | 查看客户邮箱和手机号 | 服务端返回 `b***@example.com`、`138****2222` 等脱敏值 |
| 筛选保护 | 点击“添加筛选” | 邮箱和手机号不在允许筛选字段中 |
| 类型化筛选 | `region 等于 华东` | 返回 2 行，筛选标签可清除 |
| 行详情 | 点击第一行“查看” | 显示稳定行标识与同步/ContentElement/Chunk/图谱状态 |
| 查询测试 | 输入“2026 年已完成订单的销售总额是多少？” | 展示 Plan、IR、确定性编译和真实结果 910000.00 |
| 多轮会话恢复 | 重启后打开原会话并追问“这三个区域的合计” | DSH 结合历史并重新执行数据库查询 |
| 实时计时 | 观察运行中的消息和右侧执行过程 | 2.5 秒、25 秒连续增长，完成后固定为 40 秒 |
| 执行过程 | 展开右侧事件 | 显示 Plan/IR 校验、参数化编译、查询 1 行/42 ms 等真实事件 |
| 引用定位 | 点击回答中的 `【数据1】` | 右栏切换并定位结构化依据 |
| 引用详情 | 点击“查看数据引用” | 显示数据源、数据库、查询时间、映射/Schema、QueryRun 和结果 |
| 弹窗取消 | 点击引用详情“取消” | 弹窗关闭；dialog 数量变为 0；未触发提交 |
| 控制台 | 读取页面 error 日志 | `[]` |

浏览器插件自身访问遥测域时出现过 Statsig 网络超时，该日志来自浏览器控制工具，不在被测页面 Console 中；页面 `dev.logs({level:'error'})` 返回空数组。
