# 知识洞察与知识服务升级留痕

## 变更目标

本轮在既有数据模型和服务边界上增量升级，不复制 Semantica 推理算法，不修改 DeepSeek Harness 核心 Agent Loop。知识分析继续以 Semantica `DatalogReasoner` 为推理核心；智能问答继续由锁定版本的 DeepSeek Harness 驱动。

## 主要实现

1. 知识分析新增流程导航和四套独立业务说明。
2. 场景列表改为卡片，关联真实最近运行、状态和百分比。
3. 规则中心改为规则集/规则双栏，保存前真实校验，默认展示自然语言规则，DSL 默认收起。
4. 推理结果改为运行/结论双层工作区，补充任务耗时、失败重试、来源文档定位和回滚影响预览。
5. 高级查询补充模板、格式化、分页、复制和真实 CSV 导出。
6. 智能问答改为会话/对话/依据三栏，检索范围默认可见。
7. Agent 工作过程只映射真实 DSH 事件；补充服务端时间戳、工具耗时、Turn 总耗时和事件投影去重。
8. SSE 文本采用帧批处理，补充按需自动跟随、返回最新回答、切换会话清理和引用定位。
9. 统一按钮、输入框、卡片、标签和弹窗的圆角与状态视觉。

## 边界与复用

| 领域 | 权威实现 | 本轮工作 |
|---|---|---|
| Datalog 校验与闭包推理 | Semantica Analyze / `DatalogReasoner` | 业务化输入、版本、任务、证据展示 |
| Provenance | Semantica 解析/抽取溯源与平台 Chunk | 把证据关联到文档、版本、页码和结构位置 |
| SPARQL | 授权知识投影上的现有查询服务 | 改善编辑、模板、结果和导出体验 |
| Agent Loop 与 Session | DeepSeek Harness | 事件标准化、持久化投影和 UI 呈现 |
| 混合检索与权限 | FastAPI / OpenSearch / Qdrant / FalkorDB | 右侧轨迹与排名解释，不改变权威入口 |

## 验证记录

最终自动化数量、Docker 健康状态、浏览器分辨率、真实点击步骤、控制台结果和已知限制记录在 `TEST_REPORT.md` 与 `QA_REPORT.md`。测试数据使用独立前缀，并在回归结束后通过产品接口清理；推理运行作为不可变审计记录保留，不删除既有数据或 Docker Volume。

浏览器回归期间额外发现并修复了四类真实状态问题：表单元素的命名属性与 DOM API 冲突、关联规则集已删除的历史推理运行导致空白页、服务中断遗留的 `generating` 消息导致计时无限增长，以及取消后 Harness 进程关闭事件被重复投影为失败。修复后均增加了自动化契约或状态恢复测试。
