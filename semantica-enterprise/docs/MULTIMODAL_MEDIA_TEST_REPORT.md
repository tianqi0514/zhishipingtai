## 问题发现与修复

- Tesseract 接口对 `Path` 兼容性问题：统一传入字符串路径。
- 媒体重处理直接删除元素导致 Chunk 外键冲突：改为稳定 ID upsert 和旧元素软删除。
- 模型连接测试更新时间导致缓存失效：模型指纹只包含功能配置，不包含审计时间。
- 缓存命中仍重复创建知识任务：缓存命中时复用已有知识结果。
- 视频源只有媒体成员时父 ZIP 被显示为失败：建立可追溯媒体清单元素，父快照正常就绪且不执行无价值知识加工。
- 历史失败父快照相同内容同步不能恢复：同步时自动重试失败/已上传版本。
- 图谱悬停命中排序读取空投影：过滤未投影元素，浏览器控制台复测为 0 错误。
- 时间线点击无当前状态：播放器时间更新时同步高亮活动元素。
- 模型生成的媒体跳转文本不可点击：转换为受平台权限校验的当前站点时间按钮。
- ffmpeg 测试在资源紧张环境偶发超时：测试编码固定 `ultrafast` 和单线程，仍保留真实编码/解码验证。
