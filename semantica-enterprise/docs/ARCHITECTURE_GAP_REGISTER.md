# 技术架构缺口登记簿

## 已确认的正确边界

- FastAPI 是浏览器、MCP、CLI、Harness 和应用身份的统一业务入口。
- Harness 插件只访问 `/internal/agent/*`，没有数据库和搜索引擎凭据。
- 混合检索在投影返回后重新校验 PostgreSQL 中的租户、空间、Chunk 状态和当前文档版本。
- Semantica 的解析、抽取、归一化、SearchRanker、Datalog、SPARQL 与 Provenance 通过适配器复用，没有复制核心算法。
- 结构化查询的 IR 只引用激活映射 ID，物理字段和 SQL 由服务端确定性编译。

## 架构验收不变量

1. 任何投影命中都不能绕过 PostgreSQL 权限和当前版本。
2. 任何应用/Agent 工具都不能提交任意 SQL 或得到数据库 Secret。
3. 文档内容按不可信数据处理，不能改变 Agent 系统策略。
4. 发布失败时旧 Release 必须继续可用。
5. 模型失败不能删除已成功解析的确定性结果。
6. 删除授权、撤销凭据和删除会话后，已签发短期能力必须在服务端重新校验并失效。
