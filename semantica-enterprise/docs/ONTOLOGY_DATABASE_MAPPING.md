# 本体与数据库映射

本体是业务语义权威，数据库是事实数据来源，图谱是可选的知识发布形态。三者不是同一层：

| 数据库 | 本体 | 图谱/查询含义 |
|---|---|---|
| 表或视图 | class | 每行可成为该类实例 |
| 主键/唯一组合 | 实体身份 | 形成稳定 external identity |
| 普通字段 | property | 可投影、筛选、聚合或物化为属性事实 |
| 数值字段 | metric/property | 形成可核验度量 |
| 外键 | relation | 形成确定性 Join 和可选关系事实 |
| 关联表 | relation/event | 表达多对多关系或事件 |

映射集支持创建、查看、编辑、删除、建议生成、确定性校验、管理员激活、版本列表、差异和回滚。编辑活动映射不会覆盖历史版本，而是创建新草稿。回滚会复制历史 Manifest 生成新的活动版本。

自动建议依次使用主键/唯一键、外键、表字段名称和注释、本体词条/别名、类型与有限脱敏样本。模型建议只产生草稿和证据，不能自动激活。没有主键的表仍可预览、同步和实时查询，但在配置复合稳定标识前不能物化稳定图谱实体。

映射校验确认：Schema 指纹、对象字段存在、OntologyTerm 归属、实体 primary fragment、身份字段、属性 fragment、关系端点、Join 类型兼容和重复 ID。任何被引用字段删除、不兼容类型变化或主外键变化都会把活动映射标记为 `stale` 并阻止查询。
