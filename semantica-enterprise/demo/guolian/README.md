# 国联集团组织级知识底座演示数据

> 演示数据，不代表国联集团真实经营数据。

本目录提供一组确定性、无真实个人信息的多格式演示资产，用于验证传神智库的文件解析、数据源同步、知识治理、语义建模、图谱检索、规则推演和结构化查询。所有组织、供应商、项目、金额、编号和事件均为演示构造，不应作为客户生产事实引用。

## 业务主线

演示围绕“集团采购制度执行、供应商风险传导与智慧流程中枢项目建设”展开：

1. 《集团本部采购实施细则（2025演示现行版）》规定采购范围、审批阈值和统计口径。
2. 东方智造向智慧流程中枢项目供应 NexusOne，并发生交付延期和质量异常。
3. 数字科技公司负责智慧流程中枢项目，数字化管理部负责替代方案，风险管理部负责跟踪风险。
4. 2026 年符合制度口径的有效采购金额为 1,700,000 元，其中 NexusOne 为 600,000 元；同期采购目标为 2,100,000 元。
5. 文档知识解释制度口径，数据库提供实时数值，图谱补足跨来源关系，规则推演形成可核验的风险影响结论。

## 固定数值口径

- 有效采购金额：只统计审批状态为“已通过”，且订单状态为“已签约”“执行中”或“已验收”的 2026 年订单。
- 有效采购总额：1,700,000 元。
- NexusOne 有效采购金额：600,000 元。
- 采购目标：2,100,000 元。
- 目标完成率：80.95238095%，页面可显示为 80.95%。
- 仅排除已取消、尚未应用审批条件时的订单金额：1,790,000 元。
- 高风险事件：2 起，均涉及东方智造；高风险供应商去重后为 1 家。

## 使用顺序

1. 创建或选择 `guolian-enterprise-demo` 知识空间。
2. 上传本目录文件并验证扩展名、MIME 和 UTF-8 编码。
3. 确认 Markdown、CSV、JSON、JSONL、HTML、EML、RST、TXT、XML、YAML 和 Python 均走直接文本/结构化解析，不触发 OCR。
4. 将 CSV/JSON 数据同步至独立 MySQL/PostgreSQL 演示库，并按 `structured_query_ground_truth.json` 验证实时查询。
5. 根据 `demo_ground_truth.json` 验证实体、关系、版本冲突、检索模式和规则推演。
6. 二进制图片、扫描 PDF、Office、音频和视频由 `scripts/demo/` 下的确定性生成器创建；审批单 JPG 与供应商评估扫描 PDF 是两份独立业务材料，不能复用同一画面或用文本文件冒充多模态解析结果。

## 安全边界

- 演示邮箱使用 `example.invalid`，不能外发。
- 文件不包含真实手机号、身份证号、银行卡号、数据库凭据或 API Key。
- EML 附件为标准 MIME 文本附件，内容仍为演示数据。
- 程序文件不访问网络、不连接数据库、不读写本地数据，只提供可解析的确定性规则。
- 所有页面、日志、导出和引用都应保留“演示数据”标识。
