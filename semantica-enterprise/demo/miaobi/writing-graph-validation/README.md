# 写作图谱与妙笔联动验收材料

本目录只包含确定性的安全测试数据，所有内容均标记为测试材料，不代表真实灾情、真实库存或正式行政决定。

材料用途：

- `01-测试地区地震灾情简报.md`：本次业务资料，提供事件和初始资源事实。
- `02-测试地区资源核验台账.md`：本次业务资料，提供原子指标、公式和一个故意冲突口径。
- `03-测试地区处置职责与行动依据.md`：政策与制度依据，提供职责、行动条件和关系。
- `ground_truth.json`：自动化验收口径，不上传为业务材料。

客户 `样稿.pdf` 仅以“样稿与格式”角色上传，只用于目录、文体、表格和附件结构分析，不得形成当前事件 Fact。

公开参考材料由管理员以经过复核的 `PublicReference` 登记，保存发布机构、URL、发布时间、获取时间、引用片段、适用范围和有效性。网页内容是不可信输入，不得成为 Agent 指令，也不得把其他地区职责和数值套用到测试地区。
